# 09 導入と移行（Gnosis）

2026-10-13 に simple-yurii-note を **Gnosis** に改名し、起動画面・vault 管理・設定画面・日英対応・テーマ・
インストーラーを足した。ノートの形式・同期の規則・既存のキーは変えていない。

## 名前の移行（互換）

- 関数 `simple_yurii_note#…` → `gnosis#…`、設定 `g:simple_yurii_note_*` → `g:gnosis_*`、`g:simple_yurii_search_*` → `g:gnosis_search_*`、
  `g:yurii_*` → `g:gnosis_*`。**旧名の g: 変数は読み込み時に新名へ写す**（両方あれば新名が優先）。`plugin/gnosis.vim` の冒頭。
- コマンド: 正式名はすべて `:Gnosis*`。旧 `:Yurii*` は同じ名前の `:Gnosis*` の別名（`g:gnosis_legacy_commands = 0` で定義しない）。
  短い旧名（`:NF`・`:UpdateAll`・`:SortYomi` など）も残す。
- 環境変数: `GNOSIS_ROOT` / `GNOSIS_FILE` / `GNOSIS_VIMRC` / `GNOSIS_VIM` / `GNOSIS_HOME` / `GNOSIS_LANG`。アプリは旧 `PKM_*` も読む。
  rm ガードは `GNOSIS_VAULT`（旧 `YURII_NOTE_VAULT`）。
- **変えていないもの（データ）**: vault の `.state/`・`.pkm_*.json`・ノートの形式・見出し（`### Context` など）・`## 今日のノート`。
  旧 vault の操作ガイドのファイル名 `simple-yurii-note-guide.md` はそのまま使う（Index のリンクを壊さない）。新しい vault は `gnosis-guide.md`。

## 起動の流れ

1. ランチャー → Vim（`-u <Gnosis ホーム>/vimrc`）。アプリは `--cmd let g:gnosis_start_screen = 0` を渡し、HTML の起動画面を出す
2. VimEnter で `gnosis#start#on_vim_enter()`: ファイルを指定していなければ起動画面（`autoload/gnosis/start.vim`）
3. Enter → `gnosis#start#begin()` → vault の設定を反映（言語・テーマ）→ `gnosis#startup_sequence()`
   （マウント → 検索ハイライト → ロック掃除 → 状態の移行 → root と Index → ガイド更新 → Index を開く）
   以前は VimEnter の自動コマンドがばらばらに行っていた。**Index を開く処理は other.vim の VimEnter から startup_sequence へ移した**
   （起動画面の上に Index が開いてしまうため）。

## 設定と言語

- 設定画面: Vim は `:GnosisSettings`（`autoload/gnosis/settings_ui.vim`）、アプリは起動画面の「設定」。同じ `<vault>/.gnosis/settings.json` を読み書きする。
- 優先順位: 設定画面の項目は vault の settings.json → 既定値。vault を選ぶ前は既定値（言語は OS の言語。`g:gnosis_language` で初期値を指定可）。
- 言語を変えると、メッセージ・メニュー・操作ガイド（`:GnosisGuide` / 起動時に自動）がその言語になる。ガイドの題が変わったら、ガイドへのリンクの表示名も追従させる。
- Python の補助スクリプトは `GNOSIS_LANG`（Vim が入れる）で表示を切り替える（`python/gnosis_i18n.py`）。
- 翻訳しないもの: ノートの本文・タイトル、`### Context` などの見出し、関係名（ノート・補足・資料・関連）、`attribute` の値、日記の節。

## テーマ

- 標準（ライト / ダーク）・カスタム（6 色）・追加テーマ（`Plug '作者/リポジトリ'`）。追加テーマは `作者/リポジトリ` だけを取り出して
  `git clone --depth 1` で Gnosis ホームの `themes/` へ。入力を Vim script として実行しない。
- 追加テーマは `colorscheme` のあと `g:colors_name` が変わったかで読み込めたかを確かめ、だめなら標準に戻す（端末の色数で途中で止まるテーマがある）。
- アプリには、Vim が読み込んだ色（Normal・Underlined/Identifier・Title・Visual・CursorLine）を `g:gnosis_palette` として送り、画面の色をそろえる。

## 旧環境からの移行（作者の環境）

- 本体のフォルダ（`~/.vim-simple-yurii-note/simple-yurii-note`）は vim-plug の置き場所のまま使える。`git pull` で Gnosis になる。
- アプリメニューの `simple-yurii-note.desktop` と `~/.local/bin/simple-yurii-note-app` は、互換の起動パスがあるので動く。
- 新しい起動項目を作るには `./install/install.sh`（既存の `~/.vim-simple-yurii-note/{fzf,fzf.vim,vim-surround}` は、Gnosis ホームに
  プラグインが無いあいだ読むだけで使う）。
- 端末の `yurii-note`（Konsole + `~/.vimrc-simple-yurii-note`）もそのまま動く（起動画面が出るようになる）。

## 罠（このとき踏んだもの）

- **`nnoremap <buffer> <CR> <Cmd>call f('<CR>')<CR>` の `'<CR>'` はキーに化ける**。文字として渡すなら `<lt>CR>`。
- **packpath から `$VIMRUNTIME` を外すと netrw が `E919` を出す**（`packadd netrw`）。外すのはふだんの `~/.vim/pack` だけ。
- **`vim -es` は `~/.vimrc` を読まない**（`-u` を付けたときだけ読む）。ふつうの Vim の読み込みを試すときは `--not-a-term` で。
- **xvfb にはウィンドウマネージャーが無い**ので、`maximize()` は効かない（試験は「最大化を求めたか」を見る）。作者の KDE セッションと
  D-Bus でぶつかるので、試験で kwin を起動しない。
- **同じ秒にノートを 2 つ作るとファイル名がぶつかる**（タイムスタンプ名）。試験は 1 秒あける。
- 表示名の `[ ] \` はエスケープする。リンクの解析（Vim・Python・アプリ）は `\]` などを読めるようにした。
