# 04 キー操作（主なもの）

> **注意**: この文書は古い操作を含む（`zp` / `zap` / `ca` などのキーは廃止。`zn` / `zk` / `\l` / `za` の位置キーも変わった）。最新の操作は Gnosis の操作ガイド（`guide/ja.md`）を見ること。

起動: `gnosis`（Gnosis 専用の Vim 環境。起動画面で vault を選んで Enter）。旧 `vim -u ~/.vimrc-simple-yurii-note` でも動く。

## ノート作成

| キー | 動作 |
| --- | --- |
| `zn` | 子ノート作成（`h`=今のノートのカーソル直下 / `Enter`=本文の最後 / `c`=今のノートの `### Context` 末尾 / `o`=孤立）。`h`/`Enter` は新ノートの `### Context` に元ノートが入る。`c` は元ノートが**子**になるので新ノートの**本文リンク**に元ノートが入る（`o` はリンク無し） |
| `zk` | グループノート作成（front matter に `attribute: group`）。位置キーは `zn` と同じ（`g` は無い） |
| `zk`（ビジュアル） | 選択範囲を**中身にした**グループノートを作成。選択はグループへのリンクに置き換わる。グループの `### Context` は今のノート。作成後グループを開く |

## リンク

| キー | 動作 |
| --- | --- |
| `\L`（ノーマル） | カーソル下のファイル名をリンク化 |
| `\L`（ビジュアル） | 選択範囲を表示名にした新ノートへのリンクで選択を置換。新ノートの `title` はタイムスタンプのまま。**Context は付けない**（元ノートは BackLink に出る。付けたいなら `\P`）。作成後そのノートを開く |
| `\p`（ノーマル） | リンク 1 本を今のノートに追加（`za` と同じ。`h` / `Enter` で位置を選ぶ） |
| `\p`（ビジュアル） | クリップボードのファイル名または URL を選択範囲のリンクに（ノートは開かない）。ファイルマネージャのコピー（`file://` URI）もローカルパスに直して扱う |
| `za` | クリップボード／ヤンクしたリンクを今のノートに追加（**複数行・複数リンクも全部**。同じノートは 1 本にまとめる。`zA` は 1 本ずつ表示名を聞く、`zp` / `zap` も全部）（`h`=カーソル直下 / `Enter`=本文の最後 / `t`=見出しの下（今のノートの見出しを選ぶ）/ `c`=Context末尾 / `b`=ChildBranch / `p`=ParentBranch / `r`=Related）。相手は**クリップボードかヤンクしたリンク**。相手側の `### Context` には**書かない**。Index でも通常のノートと同じ動き（位置キーを聞く。Index には `### Context` が無いので `Enter` は末尾）。index.md を開いて貼ったときは勝手に並べ替えない（並べ替えは `\ua` / `\S` のときだけ）。開かずに Index へ足したときは自動で並ぶ |
| `zA` | `za` と同じだが、追加前に**表示名**を入力する（既定は `za` が使う表示名。空 `Enter` / `Esc` で中止）。Vim 標準の折りたたみ `zA` は上書きされる。Index（index.md）でも通常のノートと同じ動き（位置キー → 表示名）。並べ替えは勝手にせず `\ua`（または `\S`）で行う |
| `zp` | 同じ追加（`h` / `Enter` / `c` / `r`）をしたうえで、`h` / `Enter` のときは**今のノートを相手の `### Context` に書く**。今のノートがグループなら親は sync が書くので何もしない |
| `\l`（ノーマル） | 全ノートを**全文検索（タイトル優先・表示はタイトル）** → 選んだノートへのリンク（`[タイトル](相対.md)`）を、`za` と同じ**置き場所キー**で入れる（`h`=カーソル直下の新しい行 / `Enter`=本文の最後 / `t`=見出しの下 / `c`=Context 末尾 / `b`=ChildBranch / `p`=ParentBranch / `r`=Related / `i`=カーソル位置にそのまま / `g`=選んだグループに今のノートを入れる）（`:LinkPick`） |
| `\l`（ビジュアル） | 同じ検索でノートを選び、**選択範囲をリンクで置換**（表示テキストは選択していた文字列。空ならノートタイトル） |
| `\P` | カーソル下の `.md` リンク先の `### Context` に、**今のノートを確認なしで** 1 本足す（`\p` の確認プロンプトの代わり） |
| `zo` | カーソル下の `.md` リンク先ノートの**見出し（アウトライン）**を fzf で選び、リンク先に `#スラッグ`（GitHub / VS Code 互換）を付ける。右ペインに本文プレビュー。先頭の「（見出しなし）」で解除。タイトルと同じ H1 と `### Context` / `Related:` / `BackLink:` は一覧に出ない（BackLink は同期で作り直されるため対象外）。詳細は `02-ノート形式.md` |

## c のあとの選択（zn / zk / za / \l。2026-10-13〜）

`w`（2026-10-15〜）: リンク先に**自動では何も書かず**、元のノートのファイル名だけ（タイトル・パス・リンク記法なし）を無名レジスタと `0` レジスタにヤンクして、リンク先を開く。`p` で貼り付けたり、自分で Markdown リンクに直したりする。元のノートの Context への追加はそのまま。複数リンクは 1 件ずつ（最初を開き、残りは `:GnosisWNext`）。

今のノート A の `### Context` にリンク先 B を入れる（`c`）と、続けて **B に A へのリンクをどう入れるか**を聞く。

| キー | B 側 |
| --- | --- |
| `Enter` | B の本文の最後（関係の節の手前） |
| `t` | B の見出しを選び、その節の最後（次の同じか上の階層の見出しの手前）。新しいノート（zn / zk）には見出しが無いので本文の最後 |
| `o` | 入れない（A の Context への追加はそのまま。操作の取り消しでも、zn の最初の `o`（孤立）とも別） |
| `Esc` | 取り消し（A にも B にも何も書かない。質問はすべて書く前に行う） |

B がグループなら、`Enter` / `t` のあとに**表示名**を聞く: 入力欄は空から。空 `Enter` = A のタイトル、入力して `Enter` = その文字、`Esc` = 取り消し。
表示名はノートの title・ファイル名を変えない。`[ ] \` はエスケープして書く。入れたリンクは本文のリンクなので、保存・同期しても残る（自動生成の BackLink とは別）。

`\l` → `n`: 選んだノートへのリンクを、**表示名を入力して**今のノートの本文の最後へ入れる（入力の規則は同じ。空 `Enter` はリンク先のタイトル）。
`\l` → `g` / `za` → `g`: 選んだノート（グループ。`attribute: group`）に、**今のノートを入れる**。そのグループの本文に今のノートへのリンクが表示名つきで入り（空 `Enter` はタイトル）、今のノートの `Group:` にそのグループが出る。今のノートの本文にはリンクを置かない。グループでないノートを選んだときは何もしない。Esc で何もしない。

## 位置キーまとめ

`zn` / `zk` / `za` / `zp` / `\p` は「リンクをどこに置くか」を 1 打で聞く。

| キー | 置き場所 |
| --- | --- |
| `h` | 今のノートのカーソル行の直下（本文） |
| `Enter` | 今のノートの本文の最後（`### Context` の直前） |
| `r` | `Related:` に**相互追加**（今のノートと相手の両方。無ければ見出しを作る。`za` / `zA` / `zp` のみ。片側で消すと次回同期で反対側からも消える） |
| `c` | 今のノートの `### Context` 末尾（`zn` / `zk` / `za` / `zA` / `zp`） |
| `b` / `p` | **Branch**。`b` = 今のノートが親・選んだ（作った）ノートが子（ChildBranch）、`p` = 選んだ（作った）ノートが親・今のノートが子（ParentBranch）。親側の `ChildBranch:` と子側の `ParentBranch:` の両方に書く（同じ処理）。親は 1 つだけ・自己参照と循環は拒否（どちらも変更しない）。`zn` / `zk` / `za` / `\l`。詳細は `03-同期の規則.md` |
| `o` | リンク無し（孤立）。`zn` / `zk` のみ |
| `Esc` / `q` | 何も追加しない |

- リンクは**1 本だけ**取る（`za` / `zp` / `\p`）。`zn` は新規ノート 1 枚。
- リンクの候補は**クリップボードかヤンクしたリンク**（カーソル下のリンクは使わない）。システムのクリップボード → `"` → `0` → `+` → `*` の順に見て、最初に実在するノートを指すリンクを使う。
- `zn` / `zk` で新ノート側に元ノートをどう書くかは位置キーで決まる。
  - `h` / `Enter` … 元ノートが**親**。新ノートの `### Context` に元ノートを置く。
  - `c` … 元ノートが**子**（今のノートの `### Context` に入るので）。新ノートの
    **本文リンク**に元ノートを置く。ここを `### Context` にすると向きが逆になり、
    循環して読めなくなるため。
  - `o` … リンク無し（孤立）。
  詳細は `06-引き継ぎ.md`。

## 新規ノート（`zn` / `zk`）の完成形

`h` / `Enter`（元ノートが親）:

```markdown
---
time: 2026-09-27 07:48:50
title: 260927074850
---

# 260927074850

### Context
[2026-09-26-sa-久しぶりの日記これまでのまとめ](260926174458.md)
BackLink:
```

`c`（元ノートが子。`zk`=グループの例）:

```markdown
---
time: 2026-09-27 08:55:58
title: 260927085557
attribute: group
---

# 260927085557

[DeepSeekへの従量課金よりもOpencode-goがいい](260927075132.md)
### Context
BackLink:
```

- `h` / `Enter` は新ノートを**本文を空のまま**にし、`### Context` にだけ
  「もと開いていたノート」を入れる（`s:simple_add_parent()`）。
- `c` は新ノートの本文に「もと開いていたノート」を**リンク 1 行**で置く
  （`s:simple_body_append_to_file()`）。グループ（`zk`）はリンクと `### Context`
  が隣り合い、普通のノート（`zn`）は上下に空行 1 つずつ。
- `h` / `Enter` / `c` のどれを選んだかは「**今のノート側**に新ノートへのリンクを
  どこへ置くか」も決める。
- `zn` で `Enter` を選んだとき、リンクが `### Context` の**上**（本文の最後）に
  くっつく場合は `s:ensure_blank_before_up()` で空行を入れる。

## タイトル・表示名

| キー | 動作 |
| --- | --- |
| `zt` | タイトル変更（空欄から開始） |
| `zT` | タイトル変更（現在タイトルを残して編集） |
| `zy` | **今開いているノート**の `title` の**よみ**を**空欄から**変更（`zt` と同じ流儀。Esc で中止）。対象ノートの `yomi:` に表示名が複数あるときは番号で表示名を選んでから編集 |
| `zY` | 同じ対象の**現在のよみ**（未登録なら pykakasi の推測）を残して編集（`zT` と同じ流儀）。全部消して `Enter` で削除。表示名の選択は `zy` と同じ |

変更すると、本文・Context・BackLink のリンク表示名が追従（自動生成名のとき）。

## 移動・閲覧

| キー | 動作 |
| --- | --- |
| `<CR>` | カーソル下のリンクを開く |
| `<Tab>` / `<S-Tab>` | 次 / 前のリンクへ |
| `gs` | vault を**全文検索（タイトル優先）**。左はタイトル、右はヒット箇所をハイライト＋ヒット行へスクロール → `Enter` でそのノートのヒット行を開く |
| `<Space>` | 今のノートに表示中のリンクだけを fzf で一覧 → `Enter` で開く。一覧にはそのページでのリンクの表示名を出し、検索は**表示名に当たったもの → ノートのタイトルに当たったもの → 本文だけに当たったもの**の順に並べる |
| `rg` | ripgrep で全文（行単位）検索（`:Rg`、fzf プレビュー付き） |
| `<BS>` | 履歴を戻る |
| `\h` | ハブ画面を開く（リンク一覧の**編集可能な Markdown**）。普通のリンクなので `1`〜`9`/`0` でそのまま移動できる |
| `\H` | 今のノートをハブにリンク 1 行として末尾へ追加 |
| `\1`〜`\9` | ハブ画面の N 番目のリンクへ直行 |
| `\0` | `\h` と同じ（ハブ画面を開く） |
| `\u`（`:GnosisOrphans`） | どこにもつながっていないノート（オーファン）の一覧を、`\h` と同じ編集可能な Markdown 画面で開く。他のノートへのリンクも、他のノートからのリンクも無いノートが対象（Index・操作ガイド・日記は数えない。日記は作ったノートへ自動でリンクするため）。開くたびに作り直す |
| `\i` | `index.md` を開く（2打） |
| `\f` | 紙PKM Index（**`Paper-Zettelkasten-Index.md` 固定**。旧タイムスタンプ名は開くとき自動で移行し、他のノートのリンクも書き換える）を作成/オープン。`Index-write` と `Folgezettel-Index` も作られる |
| `\F` | スキャン画像にフォルゲゼッテルIDを付けて vault 直下へ移動（番号付け GUI。`:GnosisScan`）。GUI の **`d` = 紙の日記として登録**（日記が書かれた日付を入力。題はデジタル日記と同じ `YYYY-MM-DD-曜日2文字`、曜日は自動。複数ページは同じ日付で続けて `d`）。日記があると Index にキーワード「日記」が自動で入り（Folgezettel-Index の先頭にも `日記` が並ぶ）、開くと**日記一覧（年・月別）**になる。月グループ（`YYYY-MM`）の中に日が日付順に並ぶ。年グループ（`YYYY`）は日記が 2 つ以上の年にまたがってから作る。GUI の日付入力の下にも、登録済みの日記一覧（新しい順・曜日とページ数つき）が出て、選ぶと日付が入る |
| `\S`（ノーマル） | バッファ内の**リンクだけの行**を表示名のよみ順（五十音 → ローマ字は末尾）に安定ソート（主に `index.md`）。`:SortYomi` と同じ。`Index_write.md` ではキーワード行（`バナナ(ばなな): 1,2`）も並べる |
| （自動） | グループ（`attribute: group`）の本文の最後のブロックに、新しいリンクを足して**保存**すると、自動で `\S` と同じよみ順に並べ直す（読み込み・前回の並べ替え以降に増えたリンクがあるときだけ。挿入モード中は待ち、Esc で保存したあとに並べる）。Index（index.md）を**開いて** `za` / `c+v` / `p` / `\p` などで貼ったときは対象外（足した位置のまま）。Index を開かずにグループにするとき（`\l` / `za` の `g`、他のノートからのリンク追加など）は、書いたあとで自動的に並べる。紙PKM の生成物・日記のグループ（`YYYY` / `YYYY-MM` / `日記`）も対象外 |
| `\S`（ビジュアル） | 選択した行のリンクだけの行を同じ規則でソート（リンクでない行は動かない） |
| `\S` の範囲 | 文章（リンクでない行）と、`### Context` / `Related:` / `BackLink:` 以降のリンクは動かさない（グループに文章があってもそのまま） |
| `\S`（グループ） | **グループでは、本文の最後の「空行で区切られたブロック」だけ**を並べる（front matter・タイトル・関係の節は除く。本文末尾の空行は探すときだけ飛ばし、空行は増減させない。コードブロックの中は対象外。リンクが 0〜1 本なら何もしない）。Index と紙PKM の生成物は従来どおり全体 |
| `\I` | カーソル行（ビジュアルは選択範囲）の画像記法のサイズを変更（`SetImageSize`。旧 `\i`） |
| `\A` | ノートアプリ（Electron、無ければブラウザ）を開く |

- ハブは **Index（PKM ルート）ごと**に `~/.vim/simple_yurii_note/hubs/<hash>.md` に
  持つ（リンクを並べただけの Markdown。そのまま編集して保存すれば反映される）。
  旧 `hubs.json` は初回にこのファイルへ自動移行（json は残る）。
- `\S` / `:SortYomi` のよみは、リンク先ノートの front matter `yomi`（`zy` で登録）を
  優先し、未登録なら pykakasi が自動変換して**その場で `yomi:` に書き込む**
  （次回以降は辞書なしで同じ並び）。`zy` は手で正しいよみに直す/消すためのキー。
  pykakasi 未導入時は Unicode 順にフォールバック（`pip install --user pykakasi`）。
  詳細は `02-ノート形式.md` / `06-引き継ぎ.md`。

## 貼り付け（クリップボード）

| キー | 動作 |
| --- | --- |
| `\v` / `\V` | システムクリップボード（PCの直近のコピー / Vimでヤンクしたもの）を `p` / `P` の要領で貼る |
| `p` / `P` | Vim 標準（`"` レジスタ） |
| `gp` | 末尾改行を落として行下に追加 |
| `<C-v>` | システムクリップボードを貼る（挿入 / ノーマル / ビジュアル） |
| `<C-c>`（ビジュアル） | 選択をシステムクリップボードへコピー |
| `"+p` / `"+P` | Vim の `+` レジスタ経由（XWayland で古いことがあるので普段は使わない） |

- この Vim は `+` / `*` レジスタ（**XWayland 側**）を**使わない**（`set clipboard=`）。
  大きなヤンクを XWayland のクリップボードブリッジに通すと KWin / Klipper ごと
  固まることがあったため。読み書きは `wl-paste` / `wl-copy`（Wayland ネイティブ）で行う。
- Vim でヤンク（`yy` / `x` / `ciw` / `"+y` / `"*y`）した内容は `wl-copy` にも流れるので、
  `\v` でも PC 側のアプリでも貼れる。同期は非同期（Vim は待たない）。

| `:GnosisRemovePassword` | vault の暗号を解除して平文に戻す（`A/note` + `A/.crypt` → ノートを `A` 直下へ） |
| `:GnosisMount` / `:GnosisLock` | vault の手動マウント／ロック（gocryptfs） |
| `:GnosisBackup [出力先]` | vault のプロジェクトフォルダ（`.crypt`・その他全部。`note/` の中身は `.crypt` の複製なので除き、空の `note/` だけ残す）を vault のパスワードで 7z 化し、`<出力先>/<日時>-<プロジェクト名>.7z` に出力（出力先は引数 → `g:gnosis_backup_dir` → 入力。パスワードは gocryptfs で検証、出来た 7z は `7z t` で検査。シンボリックリンクはリンクのまま保存） |

- `:GnosisChooseIndex` は `input()` プロンプト。既定パスを**一気に消すには `<C-u>`**
  （カーソルは文末なので全部消える）。1単語ずつなら `<C-w>`、補完は `<Tab>`/`<C-d>`。

## 日記の「今日のノート」（自動）

- **`\d`（`:GnosisToday`）… 今日の日記を開く。無ければ作る。**（日付が変わる時刻は `g:gnosis_diary_day_start_hour`、既定 5）
  開くと、「今日のノート」の節の直前に空行が3つになるよう足して（節が無ければ空の節も作る）、真ん中の空行にカーソルを置く（本文 / 空行 / ここにカーソル / 空行 / `## 今日のノート`）。新しい日記は最初からこの形（本文の余白3行＋空の「今日のノート」の節）で作られる。
- **月グループは必ず作る。** `\d` やノート作成で日記を作るとき、その月のグループ（題 `YYYY-MM`）が無ければ自動で作って、その中に日記を入れる。月グループの親は、年グループ（題 `YYYY`）があればそれ、無ければグループ `日記`（あれば）。
- **年越し。** 新しい年に入って最初に日記を作るとき（`\d` など）、年グループ（その年の `YYYY`）が無く、前の年の月グループ（親が `日記` のもの）があれば、**それまでの月グループを、年ごとの年グループ（例: `2026`）にまとめて入れ**、新しい年の年グループ（`2027`）を作って、その中に新しい月グループと日記を作る。年グループの親は `日記`。親が `日記` でない月グループ（`夢日記` の月など）は動かさない。その年の年グループは、年越しまで作らない（同じ年の間は月グループが `日記` に並ぶ）。
- `:SimpleDiaryUpdate` … 日記まわりをまとめて更新する。日付で始まる題のノートを日記に登録し、日記が無い日を作り、入っていないノートを全部さかのぼって「今日のノート」に入れ、全日記の「今日のノート」の見出しとリンクの間の空行を整える（`zn`→`t` で見出しの下に置いたノートは入れない）。

ノートを作ると（`zn` / `zk` 系・`\L` ビジュアル）、その日の日記ノートの本文 `## 今日のノート` の節にリンクが自動で足される。

- 日記 = 題が `YYYY-MM-DD-曜日2文字` だけのノート（例: `2026-10-12-MO`。末尾の `-` は付けても付けなくてもよい。自動で作る日記は付けない）。無い日は月グループ（題 `YYYY-MM`）の下に自動で作る。月グループが無く、グループ `日記` があれば月グループも作る。
- リンクは日記の**本文リンク**。新ノート側は Context ではなく BackLink に日記が出る（sync の規則どおり）。
- **グループは載せない。** 日記自身・`index.md` も載せない。
- 日記の文中にそのノートへのリンクが既にあっても、節の中に無ければ足す。
- 題が `YYYY-MM-DD-…` で始まるノート（夢日記など）は、作成時刻に関係なく**題の日付の日記**に入る。題は作成後に付けることが多いので、**保存時**にも見直して、最初に入った日記の節から外して題の日付の日記へ移す。
- 日付の無い題のノートは、作成時刻の日付。日付が変わる時刻は `g:gnosis_diary_day_start_hour`（既定 5。0〜4 時は前の日）。
- 節の見出し `## 今日のノート` と最初のリンクの間には空行を1つ空ける。最後のリンクと `### Context` の間は、空けも詰めもしない。`za` / `zn` の `Enter` で日記に足したリンクは `### Context` の直前に置き、「今日のノート」の一覧とは空行を1つ空ける。
- 日記のバッファが開いているときはバッファに直接足す（保存は自動保存）。
- 日記は `.state/diary_days.json` に記録する。日記の題を後から変えても別の日記は作らない。
- 昔の日記（題に内容が付いたもの）は、`\ua`（`:UpdateAll`）で**自動登録**される。題がその日付で始まる（グループでない）ノートが**その日に1つだけ**なら、それを日記とみなす。2つ以上ある日（日記と夢ノートなど）は曖昧なので登録せず、`\ua` が件数を知らせる。その日記ノートで `:GnosisDiaryAdopt` を実行すると登録できる。未登録の日に日付で始まる別のノートがあると、重複した日記を作らず警告する。
- **さかのぼって入れるのは最初の1回だけ。** 最初の `\ua` で、まだ日記の節に入っていないノート（この機能を入れる前に作った分）を、入れるべき日記の「今日のノート」に足す（既定で全部。`g:gnosis_diary_backfill_days` に日数を入れると直近だけ）。以後はノートを作ったとき（と題に日付を付けて保存したとき）に自動で入るだけで、`\ua` は全体を見直さない。もう一度やるには `:SimpleDiaryUpdate`。**日記が無い日は、さかのぼり追加のときに作る**（題 `YYYY-MM-DD-曜日`、`time:` はその日の 0 時）。月グループ（`YYYY-MM`）が無ければ、グループ `日記` の下に作る。その日付で始まる題の別のノート（日記かもしれないもの）があるときは、重複を避けて作らない（そのノートで `:GnosisDiaryAdopt`）。
- 設定: `g:gnosis_diary_auto`（既定 1。0 で無効）、`g:gnosis_diary_section`（既定 `今日のノート`）。
