# スマホのメモ（Gnosis メモ APK）と、とりあえず書くモード

WhatsApp の自分宛てチャットの代わりに、開いてすぐ書けるスマホのメモ帳。書いたものは PC の Gnosis に
取り込むと、1 件ずつ普通のノート（日記トピックは日記の本文）になり、つなぎ忘れが出ない。

## スマホ（`android/`）

- **開くとすぐ書ける**: 入力欄にカーソルがあり、キーボードが出る。送ると 1 件が吹き出しで並ぶ（時刻つき）。
- **トピック**: 入力欄の上のボタンで 1 タップで切り替え（初めは「日記」「メモ」。「＋ トピック」で増やす）。
  - 「日記」で書いたものは、取り込むとその日の日記の本文に `HH:MM 本文` で入る。
  - ほかのトピックは 1 件 = 1 ノート（題は 1 行目）。作った日の日記の「今日のノート」に載る。
- **長押しのボタン**: 続けて書く（このメモの子 = Branch）/ 文脈につなぐ（相手をタップ = Context）/ 書き直す /
  トピックを変える / コピー / 親から外す / 文脈を外す / 消す。つなげるのはスマホで書いたもの同士だけ。
  既にある Gnosis のノートへは、PC で取り込んだあとにつなぐ。
- **画像**: 入力欄の左のボタンで付ける。
- **定期アラーム**（右上の時計）: 初めは鳴らさない。何分おき・何時から何時までを数字で決める。
  鳴ったら通知を押すと「今まで何してた？」が日記で開く。
- **書き出し**（右上の矢印）: まだ書き出していないものを鍵付きの `.7z`（AES-256）にし、パスワードを
  クリップボードに入れる。スマホの `Download/Gnosis/` にも置く。「送る」で他のアプリからも送れる。
  書き出し済みのものは設定の「書き出し済みのメモをスマホから消す」で消せる（取り込みを確かめてから）。

## PC（Gnosis）

- `\I` / `:GnosisCaptureImport [ファイル]` … 取り込む。ファイルを指定しなければ、USB でつないだスマホ
  （adb）の `Download/Gnosis/` から最新のものを取る。無ければ `~/Downloads`・`~/ダウンロード`・`~/Desktop`
  の最新のもの。パスワードを貼り付ける（空 Enter でクリップボードの中身）。
  同じものは二度取り込まない（`.state/capture_imported.json`）。画像は vault の `capture-images/`。
  スマホでつないだ Branch と Context はそのままつながる。
- `\n` / `:GnosisQuick` … とりあえず書く。何も聞かずにまっさらなノートを開く（関係のブロックも無い）。
  作った日の日記の「今日のノート」に自動で載るので迷子にならない。
- `\u` … 未整理（どこにもつながっていないノート）。スマホのメモはトピックごとに分けて出る。
  ここからノートを開き、`\l` の `b`（Branch）や `c`（Context）、グループへの `g` でつなぐ。
- `\d` で日記を開くと、空の行には `HH:MM ` が入る（何も書かずに離れたら消える。
  `let g:gnosis_diary_time_stamp = 0` で止める）。
- WhatsApp の書き出し（txt）は `python3 python/capture_import.py whatsapp チャット.txt 出力フォルダ [トピック]`
  で `capture.json` にでき、`:GnosisCaptureImport 出力フォルダ/capture.json` で取り込める。

## APK を作る・入れる

ビルド環境は sudo なしで `~/Android` に入れてある（JDK 17・Android SDK 34・Gradle 8.7）。

```sh
cd android
export JAVA_HOME=$HOME/Android/jdk ANDROID_HOME=$HOME/Android/Sdk
./gradlew assembleDebug                       # app/build/outputs/apk/debug/app-debug.apk
$ANDROID_HOME/platform-tools/adb install -r app/build/outputs/apk/debug/app-debug.apk
```

スマホの「開発者向けオプション」で USB デバッグをオンにして USB でつなぐ。
`local.properties`（`sdk.dir=…`）はこの PC の場所なのでコミットしない。
