# 操作ガイド（Vim・`\A`・書き出し）

通常の操作は `docs/04-キー操作.md` と Vim 内の `:GnosisGuide`。ここでは、新しく加わった操作を、使う順にまとめる。**未実装・未確認のものは明記**する。

## 1. スマホのメモを取り込む（`\M`）
- `\M`（`:GnosisCaptureImport`）: USB でつないだスマホのメモを取り込む。**同じメモを何度取り込んでも増えない**。スマホで書き直したメモは、別のノートを作らず**同じノートの該当部分だけ**を更新する。PC で追記した部分は残る。日記・時系列記録・まとめるトピックに入れたメモも同じ（その行だけ更新）。
- PC とスマホが**同じ場所**を変えたときは、どちらも変えずに警告する（ノートは取り込み済みにしない）。`:GnosisCaptureConflicts` で内容を見て、`:GnosisCaptureResolve ID keep`（PC を残す）か `append`（スマホの行を引用で足す。手で統合）で解決する。
- 旧版でできた別版（`ID-2.md` など）は `:GnosisCaptureDuplicates` で一覧するだけ（何も消さない。統合は `\l` → m）。旧ノートにも追跡用の印を足すには `:GnosisCaptureBackfill`（確認だけ）→ `:GnosisCaptureBackfill apply`。
- 実機（本物のスマホ・adb）での確認は未実施。試験は取り込みデータ（`capture.json`）を使う。

## 2. 検査・Agenda
- `:GnosisCheck`: 壊れたリンク・Folgezettel の重複／抜け・孤立ノート。Enter でそのノートへ。読み取り専用。
- `:GnosisAgenda [YYYY-MM-DD]`: `- [ ]` を期限ごとに集める。Enter でその行へ、`x` で完了（繰り返しは次の回を作る）。書き方は `docs/DATA_FORMATS.md` §4。

## 3. 曼荼羅（9×9）
- **ふだんは `\A` の「曼荼羅」**（§6）で作る・直す。3×3 で一つずつ考え、副題の「広げる ▸」でそのブロックへ入る。9×9 全体でも直せる。
- Vim だけで使うとき: `:GnosisMandalaNew 主題 [副題…8個まで]` → ふつうの Markdown の表のノートができる。
- 表のマスの上で `:GnosisMandalaCell`（新しいノート）／`:GnosisMandalaCell!`（別の曼荼羅）: そのマスの文字からノートを作ってリンクにする。`:GnosisMandalaSync`: 主題・副題の対応を揃える。

## 4. 書き出し（HTML）
- `:GnosisExportSite[!] [出力先]`: 既定は `<vault>/.site`。`private: true` のノートは入らない（`!` で含める）。出力先が空でも前回の書き出しでもなければ何も書かない。
- 開くのは `index.html`。**カード・テーブル・タイムライン・番号ナビ（Folgezettel）・グラフ・検索**は、ブラウザでファイルとして直接開いて使える（ネット不要）。番号ナビのキー: ↑親 ↓最初の子 ←→兄弟 `[` `]` 番号順 Home/End、Alt+←→ 履歴。Markdown ビューア用には `FOLGEZETTEL.md`（番号表）。
- 公開前に確認: 画像の EXIF・位置情報は取り除かない（未実装）。

## 5. `\A`（Electron アプリ）
- **3 つのモード**（排他。ノートの見出しの右の「Vim / GUI 編集 / 閲覧」、または Alt+E／Alt+V）: ① Real Vim（本物の Vim）② **GUI 編集**（Vim を知らなくても書ける普通のエディタ。書式ボタン・Ctrl+Z/Y・Ctrl+B/I/K/E・Enter でリスト継続・自動保存）③ 閲覧専用（何を押してもノートは変わらない）。切り替えるときは保存してから新しいモードが読み直す。外（別の Vim・スマホ取り込み）が編集中に同じノートを書き換えたら、上書きせず確認を出す（捨てる側は `<vault>/.state/conflicts/` に退避）。
- **タブと分割**: 左端のアイコン列の「表示専用のビュー」（カード・テーブル・時系列・グラフ・番号・検索…）か、タブの列の「＋」でビューをタブで開く。ノートの見出しの「…」で右に分割・下に分割・分割の解除。タブは**ドラッグ**で並べ替え・別のペインへ移動・ペインの端へ落として分割できる。右クリックで固定・閉じる・分割。分割線をドラッグでリサイズ。「…」の「閉じたタブを開く」で開き直す。レイアウトは vault ごとに `.gnosis/workspace.json` へ保存して次回に復元する。ビューの中のノートへのリンクは、Vim のタブでそのノートを開く。
- **コマンドパレット（Ctrl+P・Ctrl+Shift+P）**: 全部の機能をここから検索して実行（モード切替・ビューを開く・タブ/分割・GUI 編集の操作・Vim の `:Gnosis*` コマンドすべて）。
- **Obsidian と同じ枠（2026-10-21〜。DECISIONS D008）**:
  - **左端のアイコン列**: いちばん上が左のバーの開け閉め。ノートを開く（Ctrl+O）・新しいノート（Ctrl+N）・今日の日記・カレンダー・索引ブラウザ・グラフ・曼荼羅・キャンバス・コマンドパレット、下に表示専用のビューと全機能。右クリックで出すアイコンを選べる。
  - **左のバー**: 上のアイコンで「索引」（索引ナビ）・「ノート」（全部のノート。Obsidian のファイル一覧と同じく絞り込みは無く、⇅ で並び替え: 作った日時・更新日時・題）・「検索」・「機能」（全部の機能をグループごとに。上の欄で探して Enter・押すと実行）を切り替える。今のパネルのアイコンをもう一度押すとバーが閉じる。
  - **右のバー**: 「リンク」（Context・親子・Group・トピック索引、**バックリンク**とその行、出ていくリンク）・「アウトライン」（見出し。押すとその行へ）。右上のボタンで開け閉め（閉じているときはタブの列の右端に開くボタン）。
  - バーの境目をドラッグで幅を変える（ダブルクリックで閉じる）。パネルのアイコンを反対側のバーへドラッグで移せる（右クリックでも）。開け閉め・幅・並びは PC ごとに覚える。バーのノートの行は、キャンバスや曼荼羅のマスへドラッグで置ける。
  - **ノートの見出し**: 戻る・進む・Index からの道と題・モード・「…」（索引に載せる・トピック索引・分割・閉じたタブを開く）。Vim のタブにはノートの題が出る。
  - **キー**: Ctrl+P パレット・Ctrl+O クイックスイッチャー（Obsidian と同じあいまい検索。文字が順に出れば当たる。題のよみ・ファイル名でも。何も打たなければ最近開いたノート。Enter で開く、無ければ Shift+Enter かいちばん下の行でその題のノートを作る）・Ctrl+N 新しいノート・Ctrl+W タブを閉じる（Vim のタブは閉じない）・Ctrl+Tab／Ctrl+Shift+Tab タブを移る・Ctrl+Shift+F 検索（左のバー）。**Vim の画面ではノーマルモードのときだけ**（挿入モードの Ctrl+P/N などは Vim のまま。ノーマルモードの Vim の Ctrl+O は使えなくなるので、戻るは ⌫ か Alt+←）。
- **検索（左のバー・Ctrl+Shift+F。Obsidian と同じ書き方）**: 語を空白で並べると全部を含むノート（ノートのどこにあってもよい）・`"…"` はその並びのまま・`OR`・`-語` は含まない・`( )` でまとめる・`/正規表現/`・`file:`（ファイル名と題）・`path:`・`content:`・`tag:`・`line:( )`（同じ行）・`block:( )`（同じ段落）・`section:( )`（同じ見出しの下）・`task:`／`task-todo:`／`task-done:`・`match-case:`／`ignore-case:`・`[項目]`／`[項目:値]`（front matter）。欄が空のとき、書き方の一覧から選んで入れられる。結果はノートごとにまとめ、当たった語に色。行を押すとそのノートのその行へ。Aa（大文字小文字を区別）・?（検索語の説明）・≡（畳む）・⇅（並び替え: 題・更新日時・作った日時）。ノートを結果からキャンバスや曼荼羅へドラッグできる。
- **題の同期（Obsidian と同じ）**: 本文の `# 見出し`（H1）か front matter の `title:` の片方を書き換えて保存すると、もう片方もそろう。ほかのノートの古い題のリンクの表示名も、保存のあとの同期で直る（zt と同じ）。Vim でも GUI 編集でも。
- 見た目（文字・背景・見出しの大きさ・行の幅 700px・ボタン・ダイアログ）は Obsidian に合わせている。リンクの色は Gnosis のまま。アクセントは黒（ダークでは明るい灰色）。
- **未実装**: ペインごとの履歴、タッチ操作・アクセシビリティの追加対応、複数カーソル、ノート名の補完。

## 6. `\A` の作業台（2026-10-21〜）— Vim は書く場所、`\A` はそれ以上のことをする場所
読むのは `python/app_model.py`（読み取り専用）、**書くのはいつも Vim**（`gnosis#app_op` が zn / zk / \l / \d と同じ処理を通す。保存時の同期も全部走る）。

### 索引ナビ（左のバーの「索引」。Alt+I で索引語を探す）
Vim で開いているノートに付いていく。
- **Index からの道**: 「Index › ハーブ › ローズマリー › 栽培」のように、ダブルインデックスの辿り方（索引の中の名前で出す）。名前を押すとそのノートへ。小さな ▤ はその段のトピック索引へ。索引から辿れないノートは「索引からまだ辿れません」と、親（ParentBranch）の道。
- **載っている索引**: どの索引に、どの名前（索引語）で載っているか（別名も全部）。「＋ 載せる」で索引を選んで名前とよみを入れると、Vim が `\l` の g と同じ処理で載せ、よみの順に並べる。
- **トピック索引**: そのノートの BranchGroup: の索引の項目を、その場で一覧。項目の ▸ で、さらに奥のトピック索引をノートを開かずに開ける。「＋ 作る」でトピック索引を作る（`zk → n` と同じ。Global Index のリンクは書き換えない）。
- 索引（グループ）を開いているときは**この索引の項目**と「＋ 新しいノート」（`zn → Enter` と同じ。起点のノートが親になる）・「＋ 既存」。
- **索引語で探す**（上の欄。Alt+I）: 同じ「栽培」でも「Index › ハーブ › 栽培」「Index › ハーブ › ローズマリー › 栽培」と、**どの索引の名前か**が分かる形で出す。よみ・ひらがな/カタカナの違いでも見つかる。

### 索引ブラウザ（タブ）
Global Index → ノート → そのノートのトピック索引の項目 → … を**列で**辿る（クリックで奥へ・ダブルクリックや Enter で Vim で開く・←→↑↓）。右に本文のプレビューと「トピック索引を作る」「索引に載せる」。上の欄で探すと、その項目の場所まで列が開く。**「索引に無いノート」**で、Global Index から辿れないノート（日記などは除く）を一覧し、その場で載せられる。

### カレンダー（タブ。Alt+C）
月の表に 📔 日記・🌙 時系列記録・📝 その日に作ったノート・☐ 期限のタスク・✅ 終えた数。日を押すと右にその日の中身。
- 日記を開く／その日の日記を作って開く（`\d` と同じ木の形。まだ来ていない日は作らない）。ダブルクリック・Enter でも。
- タスクのチェックで完了（Vim が保存する。繰り返しは次の回を作る）。「＋ タスク」（a）で、選んだ日が期限のタスクを**今日の日記**に書く（スマホの予定にも送られる）。
- ←→↑↓ で日、PageUp/PageDown で月、t で今日。

### 曼荼羅（タブ）
左端のアイコン列の「曼荼羅」: 今のノートが曼荼羅なら開く、違えば新しく作る（主題と副題 8 つ。今日の日記に載る）。
- **3×3 で考える**: 中心（主題と 8 つの副題）から始め、副題の「広げる ▸」（Alt+↓）でそのブロックへ。Alt+↑ で中心へ。下の小さな 3×3 で各ブロックの埋まり具合と移動。
- **9×9 全体**: 全部のマスを見ながら直す。
- 副題は 2 か所（中心のブロックと周りのブロックの真ん中）を自動でそろえる。Enter / Tab で次のマス。
- マスの「ノートに」「曼荼羅に」: その文字で新しいノート（別の曼荼羅）を作ってマスをリンクにする。リンクのマスは名前だけを見せ、押すと中身を直せる。
- **9 つ以上（副題が 8 つで足りないとき）**: 最後の曼荼羅の 8 つの副題が埋まると、**下に同じ主題の曼荼羅が続きます**（スクロールで次へ）。打ち始めると、同じノートの 2 枚目・3 枚目の表として保存されます（Markdown ビューアでも表が縦に並んで読めます）。
- **並び替え**（上の欄。表示だけでファイルは変えない）: ファイルの順・あいうえお順（よみ）・埋まっている順・空いている順。「この並びで保存」で、副題とそのまわりのマスをまとめてその順に書き直す。
- **索引を曼荼羅で見る**: 索引（グループ）か、トピック索引のあるノートを開いて、左端の「曼荼羅」・索引のパネルの ▦・「…」メニュー・パレットの「今の索引を曼荼羅で見る」。真ん中に索引の題、周りに項目、そのまわりに各項目のトピック索引の項目。項目を押すと Vim で開く。「この索引へ ▸▸」でトピック索引を真ん中にして入る（「‹ 戻る」で戻る）。項目が 8 つを超えると下に続く。並び替えは索引の順・あいうえお順・項目の多い順・少ない順・新しい順・古い順。空いた枠の「＋ 新しいノート」「＋ 既存」（ノートのドラッグでも）で索引に足せる（書くのは Vim）。
- **既存のノートを入れる**: マスの「既存…」（空のマスは「既存のノート…」）で題から選ぶ。マスに文字があればそれを表示名に、無ければノートの題が入る。左右のバー（ノート・リンク・索引）や索引ブラウザのノートを**マスへドラッグ**しても入る。副題のマスなら 2 か所とも同じリンクになる。「外す」でリンクだけを外して文字を残す。
- マスの道具は、マスにマウスを乗せたとき・打っているときだけ出る（「広げる ▸」はいつも出る）。
- 保存は Vim。保存のあとにほかで変わっていたら、マスごとに 3-way で合わせる（自分が直したマスは自分の文字。両方が同じマスを違う文字にしたときだけ知らせる）。

### キャンバス（タブ）
ノートのカードと文字のカードを置いて、名前つきの矢印でつなぐ図。保存はふつうの Markdown ノート（`canvas: true`。置いたノートへのリンクの行と、` ```gnosis-canvas ` のブロック。形は `docs/DATA_FORMATS.md`）。
- 「＋ ノート」（n）・「＋ 文字」（t・空いた所をダブルクリック）。サイドバー・索引ブラウザの項目をドラッグして置ける。
- カードはドラッグで移動、右下で大きさ、右端の ● から引いて矢印。矢印をダブルクリックで名前。Delete で消す。右クリックで色。f で全体を表示。ホイールで拡大縮小。
- ノートのカードの「索引を広げる」: そのノートのトピック索引の項目を、**索引の名前つきの矢印**でまわりに並べる（ダブルインデックスを図で見る）。
