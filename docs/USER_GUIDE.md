# 操作ガイド（Vim・`\c`・書き出し）

通常の操作は `docs/04-キー操作.md` と Vim 内の `:GnosisGuide`。ここでは、新しく加わった操作を、使う順にまとめる。**未実装・未確認のものは明記**する。

## 1. スマホのメモを取り込む（`\M`）
- `\M`（`:GnosisCaptureImport`）: USB でつないだスマホのメモを取り込む。**同じメモを何度取り込んでも増えない**。スマホで書き直したメモは、別のノートを作らず**同じノートの該当部分だけ**を更新する。PC で追記した部分は残る。日記・時系列記録・まとめるトピックに入れたメモも同じ（その行だけ更新）。
- PC とスマホが**同じ場所**を変えたときは、どちらも変えずに警告する（ノートは取り込み済みにしない）。`:GnosisCaptureConflicts` で内容を見て、`:GnosisCaptureResolve ID keep`（PC を残す）か `append`（スマホの行を引用で足す。手で統合）で解決する。
- 旧版でできた別版（`ID-2.md` など）は `:GnosisCaptureDuplicates` で一覧するだけ（何も消さない。統合は `\l` → m）。旧ノートにも追跡用の印を足すには `:GnosisCaptureBackfill`（確認だけ）→ `:GnosisCaptureBackfill apply`。
- 実機（本物のスマホ・adb）での確認は未実施。試験は取り込みデータ（`capture.json`）を使う。

## 2. 検査・Agenda
- `:GnosisCheck`: 壊れたリンク・Folgezettel の重複／抜け・孤立ノート。Enter でそのノートへ。読み取り専用。
- `:GnosisAgenda [YYYY-MM-DD]`: `- [ ]` を期限ごとに集める。Enter でその行へ、`x` で完了（繰り返しは次の回を作る）。書き方は `docs/DATA_FORMATS.md` §4。

## 3. 曼荼羅（9×9）
- **ふだんは `\c` の「曼荼羅」**（§6）で作る・直す。3×3 で一つずつ考え、副題の「広げる ▸」でそのブロックへ入る。9×9 全体でも直せる。
- Vim だけで使うとき: `:GnosisMandalaNew 主題 [副題…8個まで]` → ふつうの Markdown の表のノートができる。
- 表のマスの上で `:GnosisMandalaCell`（新しいノート）／`:GnosisMandalaCell!`（別の曼荼羅）: そのマスの文字からノートを作ってリンクにする。`:GnosisMandalaSync`: 主題・副題の対応を揃える。

## 4. 書き出し（HTML）
- `:GnosisExportSite[!] [出力先]`: 既定は `<vault>/.site`。`private: true` のノートは入らない（`!` で含める）。出力先が空でも前回の書き出しでもなければ何も書かない。
- 開くのは `index.html`。**カード・テーブル・タイムライン・番号ナビ（Folgezettel）・グラフ・検索**は、ブラウザでファイルとして直接開いて使える（ネット不要）。番号ナビのキー: ↑親 ↓最初の子 ←→兄弟 `[` `]` 番号順 Home/End、Alt+←→ 履歴。Markdown ビューア用には `FOLGEZETTEL.md`（番号表）。
- 公開前に確認: 画像の EXIF・位置情報は取り除かない（未実装）。

## 6. 曼荼羅ビュー（CUI。`<Space>`。2026-10-22〜、2026-10-23 に作り直し）
中心のノートの周りに、つながっているノートを 8 つずつ並べて歩く。**読むだけ**で、ノートは書き換えない（書くのは今までの Vim の操作。`\l` の選ぶモードだけは、`e` で決めたときに索引へ追加する）。元データは `python/mandala_cache.py`（SQLite のキャッシュ。`<vault>/.gnosis/cache/`。派生データで、いつでも作り直せる）。
- 速さ: 解析結果をキャッシュして、変わったファイルだけ読み直す。Vim は中心ごとに必要な分だけ受け取る。実測（疑似 vault）: 10 万件で構築 6 秒・開くのは 0.3 秒未満、100 万件でも初回の構築 約 100 秒のあとは開くのが 0.3 秒・中心の移動 0.1 秒。保存したノートだけ読み直す。走査が重い vault は、開くのを待たせず裏で更新する。
- `<Space>`: 曼荼羅（左）とふつうのノート（右）を行き来する。起動したときも曼荼羅が左半分に出ている（設定 `mandalaOnStart`・`:GnosisSettings` で切り替え。既定オン）。旧 `<Space>`（リンク先の検索）は `:GnosisLocalLinks`。
- 周りの並びと色（色だけで区別）: 索引・グループ → 親 → 文脈 → 引用（このノートが文中で引用しているもの）→ BackLink（このノートを引用しているもの）→ 子 → 関連（`Related:`）→ 予測関連。どれも違う色（索引=ピンク・グループ=黄・親=青・文脈=紫・引用=橙・BackLink=灰白・子=青緑・関連=緑・予測関連=ベージュ・ノート=灰）。向かってくる親子・文脈・関連（相手のファイルにだけ書かれたもの）も出す。
- モード: `a` 全体（標準）・`i` グループ・索引だけ。重ねる `c`（近いグループ）・`r`（予測関連）はオン/オフで、どのモードにも重なる。上の 1 行に今の状態が出る。
- `hjkl` / 矢印で動く（右のノートはそのマスに切り替わる。カーソルは画面の一番下の行。曼荼羅の中心は変わらない）。`1`-`8`（左上から時計回り 8 1 2 / 7 _ 3 / 6 5 4。9 と 0 が中心）・`Enter` で中心にする・`b` / `⌫` で一つ前・`Tab` / `S-Tab` で今いる 3×3 の 中心 → 1 … 8 を順に（9×9 では外側のブロックの中。最後・最初で止まり、`[` `]` のページは動かさない）・`gs` で全文検索して中心にする。
- 曼荼羅の左上（`[a]` のすぐ後ろ）に、何枚目の曼荼羅かを常に出す（`1/1`・`3/10`。`#` で数字を消しても出る）。`[` `]` は、9×9 では、カーソルがあるブロックのページを送る（周りのブロックにカーソルがあれば周りのページ、中心のブロックなら中心のページ。外向き `v` では中心の 80 件ごとのページ）。`y` は `c` と `r` をまとめてオン/オフ（オフにしたときの状態を覚えていて、もう一度で戻る）。
- 外向き `v` の深さ: `+` を押すと下の入力欄が出るので、深さの数字（1〜10）を打つ。1 は中心の直接のつながりだけ、2 以上はそこからさらにつながるノートも、深さ順に外向きの輪に並べる（同じノートは 1 回。最大 300 件）。ヘッダーに `v:外向き 深さ2`、選んでいるマスの説明に `深さ 2` と出る。設定の画面（`'`）の「外向きの深さ」からも。
- `s`（検索）は、題だけでなくファイル名（`index.md` など）も探し、大文字小文字・全角半角・カタカナ/ひらがなの違いを無視する。題やファイル名に合うものが先。厳密に合うものが無いときは「文字が順に並んでいればよい」曖昧な一致も使う。`m` `x` `s` の入力欄では端末のカーソルを出し、`q` でやめたあと入力欄の文字は残らない。曼荼羅を開いたまま右のノートで挿入モードにしても、左下（曼荼羅の窓）のモード表示が INSERT になる。
- ``` で囲んだコードは、文字の部分だけでなく行全体（右端まで）がうす灰色になる。
- 曼荼羅のモードに「親子だけ」を追加（`,`）。中心のノートの親（`ParentBranch:`、または相手の `ChildBranch:` に自分が書かれているもの）と子（`ChildBranch:`、または相手の `ParentBranch:` に自分が書かれているもの。自分の `ChildBranch:` に無くても出す）だけを周りに並べる。`a` 全体 / `i` 索引だけ / `,` 親子だけ。
- `'` … 曼荼羅の右に設定の画面が出る（`q` で閉じる）。モード・重ねる（`c` `r`）・数字キーの動き・番号・本文・見出し・全画面・外向き・近さ順をその場で切り替え（ふだんのキーもそのまま使える）、下の段でプリセットを呼び出す（Enter か番号）・`s` 新しく保存・`o` 上書き・`n` 名前・`d` 消す。
- 探す: `s` 検索（結果が周りに並ぶ）・`x` 題で絞り込み・`m` ハイライト → `n` / `N`。`q` はかかっているものを新しいほうから 1 つずつやめ、何もなければ閉じる。`Q` は全部閉じる。入力欄と fzf の中は `Esc` / `Ctrl-C`。
- 近さ順・ページ・数字: `v` 外向き（リンクを内側から外側へ 1 つずつ最大 80 個）・`w` 近さ順（3×3 でも効く。9×9 では `d` で外側の基準を「中心に近い」⇔「そのブロック自身に近い」）・`[` `]` 中心の周りのページ・`{` `}` 外側のブロックのページ（`1/2` の形）・`#` 数字（番号とページ）を出す / 隠す・中心と同じノートが外側にも出たら色を反転して目立たせる。
- 画面: `f`（9×9）でも右のノートの窓は出たまま・`p` で隠す / 出す（YAML・上下の `:` 系は `\zz` の設定どおり。`Space` で入ってふつうに動かし、カーソルは画面の一番下の行）・`<` `>` 画面の幅（曼荼羅の窓と右の窓の境目。3×3 も 9×9 も）・`(` `)` 曼荼羅の盤面そのものの幅（横に伸ばす / 縮める）・`=` 正方形・半々に戻す。どちらも閉じても覚えている（`mandala.json`）。
- 文字サイズ: `\+` `\-` でその場だけ（保存しない）、`\=` で保存してある大きさに戻す（どの画面でも）。
- `?`: 案内を画面中央のポップアップで出す（`q` で閉じる）。`f` 全画面 9×9（真ん中の周りの 8 マスと、それぞれの曼荼羅の中心のマスが同じ薄い色）・`< >` 幅・`z` 中央・。
- `\l` → `e` → `g`（旧 `\g` を置き換え）: 入れるノートを曼荼羅で選び（`e`）、置き場所のキー `g` で入れ先のグループを曼荼羅で選ぶ（`c` が自動オン・曼荼羅は閉じない）。グループが中心のとき `e` で決定、`I` は Index に追加（そのトピックの入り口）、`t` は入れるノートの見出しを選んで、その見出しへ飛ぶリンクで入れる（表示名はそのまま。`q` で見出しの選択だけ取り消せる）、`o` は入れるノート（元のノート）を右に見る / 戻る、`q` で選ぶモードだけ終わる。
- 曼荼羅の窓にほかのノートが開こうとしたら（`\i` など）、右の窓に開く（曼荼羅は壊れない。中心も合わせる）。
- 未実装: ノートの近い Folgezettel 的な関連を出すモード（後回し）。大きな vault（2 万件超）の `c` / `r` も、小さな vault と同じ手がかり（番号・つながり・題の言葉・歩いた近さ・本文の内容）を、全体を読まずに求める（キャッシュの番号と題の言葉の索引＋狭い候補だけ。10 万件で 0.05 秒・小さな vault の結果と上位 20 件の 5〜9 割が一致）。

## 7. ノートの画像をポップアップで見る（`gz`）
- `gz` … 今のノートの画像の一覧が出る。カーソルの行に画像があれば、その画像を選んだ状態で出る。`j` `k`（`↑` `↓`）で選ぶ、数字で直行、`Enter`（`l`）で見る、`q` `Esc` で閉じる。画像が 1 枚だけのノートは、一覧なしでその画像を開く。既定は外のビューア（xdg-open）で開く（ズーム・画質はビューア任せ）。`\zz` の窓の一番下「gz で画像を開く方法」で xdg-open ⇔ sixel（この端末の中）を切り替える（vault の設定 `imageViewer`。`g:gnosis_image_viewer` があればそちらが先）。
- sixel にしたとき、画像の表示中: `j` `n` `l` `Space` で次、`k` `p` `h` で前、それ以外のキー（`q` `Esc` `Enter`）で一覧に戻る。一覧を閉じたあと、カーソルはノートの元の位置にある。
- ノートを開くと、`![](画像)` だけの行の下に画像がそのまま表示される（sixel の端末のみ。画像の高さぶん、下に空きの行ができる。ファイルは変わらない）。`\zz` の窓の「画像」をオンにすると隠す（表示しない）。`a`（全部オン／オフ）では切り替わらない。vault の設定 `hide.image`。画像は `~/.cache/gnosis/sixel` に縮小して控える。ポップアップ（曼荼羅の `?` など）が開いている間は描かない。
- `\zz` の窓の下の 2 行: 「gz で画像を開く方法」（xdg-open ⇔ sixel）と「挿入モードで、カーソルの行のリンクの中身を見せて編集する」（vault の設定 `linkEditInsert`。オンのあいだ、挿入モードで `[名前](ファイル)` のカーソルの行だけ元の書き方が見える。ノーマルモードでは今までどおり隠す）。`\c` のアプリでも同じ設定が効く（画像を表示しない・挿入モードのリンクの中身）。
- `\c` の見た目は CUI と同じ: 「テーマ（ダーク／ライト）」を切り替えると、CUI も `\c` も同じ色になる（ダークは CUI のダークと同じ、ライトは Brave の Markdown Viewer 拡張＝GitHub スタイルに合わせた色）。ライトではカーソルが濃い塊で出て、リンクの上でも文字が読める。リンクの番号の札は、ライトでも CUI ダークと同じ灰色と黒。`:GnosisSettings` は、曼荼羅が開いているときは新しいタブで開く（`q` で閉じる）。
- `gz` で外のビューアに渡す画像は、このノートの画像だけを `~/.cache/gnosis/view/` にコピーしたもの（ビューアが同じフォルダの他の画像まで前後に出さないため）。一覧の `j` `k` は端で止まり、ループしない。
- 端末に画像を出す方式は sixel（Konsole 22.04 以降・foot・WezTerm・mlterm など）。ノートの中の画像の表示は、端末が sixel に対応していれば出る（`gz` の開き方の設定とは別）。tmux の中や非対応の端末では出ない。`g:gnosis_image_viewer = 'sixel'` / `'external'` / `'auto'` で固定できる。画像の拡大縮小はセルの大きさに合わせる（自動で取れないときは環境変数 `GNOSIS_CELL_PX=10x20`）。
- 画像の拾い方は `\gi`（ブラウザのギャラリー）と同じ。
