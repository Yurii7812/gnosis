# 操作ガイド（Vim・`\c`・書き出し）

通常の操作は `docs/04-キー操作.md` と Vim 内の `:GnosisGuide`。ここでは、新しく加わった操作を、使う順にまとめる。**未実装・未確認のものは明記**する。

## 1. スマホのメモを取り込む（`\M`）
- `\M`（`:GnosisCaptureImport`）: USB でつないだスマホのメモを取り込む。**同じメモを何度取り込んでも増えない**。スマホで書き直したメモは、別のノートを作らず**同じノートの該当部分だけ**を更新する。PC で追記した部分は残る。日記・時系列記録・まとめるトピックに入れたメモも同じ（その行だけ更新）。
- PC とスマホが**同じ場所**を変えたときは、どちらも変えずに警告する（ノートは取り込み済みにしない）。`:GnosisCaptureConflicts` で内容を見て、`:GnosisCaptureResolve ID keep`（PC を残す）か `append`（スマホの行を引用で足す。手で統合）で解決する。
- 旧版でできた別版（`ID-2.md` など）は `:GnosisCaptureDuplicates` で一覧するだけ（何も消さない。統合は `\l` → m）。旧ノートにも追跡用の印を足すには `:GnosisCaptureBackfill`（確認だけ）→ `:GnosisCaptureBackfill apply`。
- 実機（本物のスマホ・adb）での確認は未実施。試験は取り込みデータ（`capture.json`）を使う。

## 2. 検査・Agenda
- `:GnosisCheck`: 壊れたリンク・Folgezettel の重複／抜け・孤立ノート。Enter でそのノートへ。読み取り専用。
- `:GnosisAgenda [YYYY-MM-DD]`: `- [ ]` を期限ごとに集める。Enter でその行へ、`x` で完了（繰り返しは次の回を作る）。書き方は `docs/DATA_FORMATS.md` §4。

## 3. 曼荼羅（9×9）
- **ふだんは `\c` の「曼荼羅」**（§6）で作る・直す。3×3 で一つずつ考え、副題の「広げる ▸」でそのブロックへ入る。9×9 全体でも直せる。
- Vim だけで使うとき: `:GnosisMandalaNew 主題 [副題…8個まで]` → ふつうの Markdown の表のノートができる。
- 表のマスの上で `:GnosisMandalaCell`（新しいノート）／`:GnosisMandalaCell!`（別の曼荼羅）: そのマスの文字からノートを作ってリンクにする。`:GnosisMandalaSync`: 主題・副題の対応を揃える。

## 4. 書き出し（HTML）
- `:GnosisExportSite[!] [出力先]`: 既定は `<vault>/.site`。`private: true` のノートは入らない（`!` で含める）。出力先が空でも前回の書き出しでもなければ何も書かない。
- 開くのは `index.html`。**カード・テーブル・タイムライン・番号ナビ（Folgezettel）・グラフ・検索**は、ブラウザでファイルとして直接開いて使える（ネット不要）。番号ナビのキー: ↑親 ↓最初の子 ←→兄弟 `[` `]` 番号順 Home/End、Alt+←→ 履歴。Markdown ビューア用には `FOLGEZETTEL.md`（番号表）。
- 公開前に確認: 画像の EXIF・位置情報は取り除かない（未実装）。

## 6. 曼荼羅ビュー（CUI。`<Space>`。2026-10-22〜）
中心のノートの周りに、つながっているノートを 8 つずつ並べて歩く。**読むだけ**で、ノートは書き換えない（書くのは今までの Vim の操作）。元データは `python/mandala_view.py`。
- `<Space>`: 曼荼羅（左）とふつうのノート（右）を行き来する。旧 `<Space>`（リンク先の検索）は `:GnosisLocalLinks`。
- 中心が**索引**なら所属する索引（`Group:` / `BranchGroup:`。**Index も**）のあとに載っているノートを、**ノート**なら所属する索引を周りに出す。8 つを超えたら 2 枚目以降（`[` `]`）。分割は左右半々、マスは見た目が正方形で、盤面は窓の中央。マスは種類で色と記号が付く（◆索引・▲親・▼子・◇Context・≈関連・←BackLink・無印=ノート）。見出しの下に凡例、下の 1 行にカーソルのマスの題・種類・理由。
- マスの `Enter`: そのマスを中心にする。ノートなら右にそのノートが開き、カーソルは曼荼羅に残る。`-` / `⌫` で一つ前。
- `hjkl` / 矢印で動く。`hjkl` / 矢印でカーソルを動かすと**右のノートがそのマスのノートに切り替わる**（曼荼羅の中心は変わらない）。`1`-`8`（`1 2 3 / 4 _ 5 / 6 7 8` の並び）はそのマスへ（既定は**そのまま中心にする**。`t` で「移動して中心に」⇔「カーソルだけ」。モードの行に今の状態が出る。`0` は中心のノート）。モードは英字（見出しの下の行に `全体:a 索引:g ノート:n 近い索引:c 関連:r` と出る）: `a` 全体・`g` 索引だけ・`n` ノートだけ・`r` **関連**（索引もノートも関連の強い順。直接のつながり・同じ索引・Folgezettel の枝・題の言葉・本文の内容（TF-IDF）・つながりを歩いた近さの合計。理由つき。`python/mandala_view.py related`）・`c` **近い索引**（すでに所属している索引が先、そのあとに Folgezettel の枝・つながり・題の言葉が近いのに未所属の索引を、理由つきで近い順に。`python/mandala_view.py near`）。`s`: 検索（題・本文を vault 全体から。結果が周りに並び、真ん中に「検索: 語」）。`/`: ふつうの検索のように語をハイライトしてヒットのマスへ飛ぶ（複数枚あれば別の枚へも。`Tab` / `S-Tab` で次・前、`Esc` で解除）。`e`: 今の周りを題で絞り込む。ノートが中心のときの「ノートだけ」は ParentBranch・ChildBranch・Context・Related・BackLink・本文のリンク。
- `f`: 全画面の **9×9**（周りの 8 マスがそれぞれ自分の曼荼羅を持つ。番号は 9×9 でも出る。数字キーはそのブロックの真ん中のマスが対象）⇔ 分割の 3×3。
- `\g`: 今のノートを載せる索引を曼荼羅で選ぶ。今のノートが中心で、**近い索引**が理由つきで周りに出る（手がかりが無ければ Index の索引）。`e` で題を絞り込み（索引を全部から）、移動して、**索引が中心のとき `Enter`** で決定（表示名とよみを聞く。`\l` → `g` と同じ処理）。
- 未実装: ノートの近い Folgezettel 的な関連を出すモード（後回し）。
