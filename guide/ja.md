このノートは Gnosis の操作ガイド。**全キーはここに集約**する。
設定画面（`:GnosisSettings`）で言語を変えると、このガイドもその言語で作り直される。**Vim の基本操作は末尾**。

## ふだんの流れ

- 書く … 今のノートで `zn` → `Enter`（本文の最後にリンク）か `h`（カーソル直下）。元のノートが親・新しいノートが子の Branch（`ParentBranch:` / `ChildBranch:`）が自動で付く
- きっかけを残す … `zn` / `\l` / `za` のあと `c`。相手（B）の `Context:` に今のノート（A）が入る。続けて A のどこに B を置くか（`Enter` / `t` / `h` / `w`）を選ぶ
- まとめる … Index などのグループの上で `zn` → `Enter`。表示名を付けてグループに登録し、索引を `\S` と同じ規則で並べ替える
- 派生させる … 起点のノートで `zk` → `n`。そのノートから分岐するグループ（BranchGroup）を作る（トピックの Index など。グループの上では作らない）
- つなぐ … `\l` で探して置く。グループに入るときは `\l` でグループを選んで `g`。文脈だけ足すなら `\P`
- 1 日の終わり … `\d` の日記の「今日のノート」に、その日に作ったノートが並ぶ。紙の日記は `\F` で取り込むと、その日の日記からリンクされる

## 起動・vault・設定

- 起動画面 … Chnoubis のシンボル・選択中の vault・`Enter` で開始。`v` で vault の選択・管理、`s` で設定、`q` で終了
- vault の一覧 … `j` / `k` で選ぶ ・ `Enter` で開く ・ `a` 既存のフォルダを登録 ・ `n` 新しい vault を作る ・ `d` 一覧から外す（ノートとフォルダは消さない） ・ `Esc` 戻る
- `:GnosisStart` 起動画面 ・ `:GnosisVaults` vault の一覧（使用中に切り替える） ・ `:GnosisSettings` 設定画面
- 設定は vault ごと（`.gnosis/settings.json`）: 言語・起動時に最大化・通常のウィンドウサイズ・テーマ（ダーク／ライト）・追加テーマ・カスタム配色。文字サイズ・フォント・行間・使う端末は Gnosis 全体（Gnosis ホームの `terminal.json`）
- `:GnosisThemeAdd` `Plug '作者/リポジトリ'` … GitHub の Vim テーマを追加してこの vault のテーマにする ・ `:GnosisThemeReset` 標準テーマに戻す
- 配色エディタ（設定の「配色を作る・直す」）では、背景・本文・リンク・見出し・選択範囲・カーソル行に加えて、**リンクの手前の番号（1〜9・0・g1 …）の文字色と背景色**も決められる。変えるとすぐプレビュー（番号つきの例）に出る。決めなければ今までどおり（文字=背景色・札=補助の色）
- `:GnosisFontSize` 文字サイズ（`20` / `+1` / `-1` / `reset`。保存して、できる端末ではその場で反映） ・ `:GnosisLinkSource on` リンクを展開して編集するモード、`off` で表示名だけに戻す（引数なしは切り替え。このノートだけ）。`A` で行末へ追記するときには自動展開しない
- アプリでは `Ctrl` + `+` / `-` / `0` で画面全体の拡大・縮小・元に戻す（その場だけ。文字サイズの設定は変わらない）
- GUI 版 Vim では `<C-=>` / `<C-+>` / `<C-->` / `<C-0>` で文字の大きさをその場だけ変える。端末の `Ctrl` + `+` / `-` / `0` は端末が処理し、保存されない。保存される大きさは設定画面の文字サイズで `+` / `-` / `0`（Konsole・kitty・Alacritty の Gnosis の窓ではその場で変わる。他の端末は次に Gnosis の窓を開いたとき）

## ノート作成

- `zn` … ノート作成。位置キーを 1 つ選ぶ（ほかのキーは何もしない）:
  `Enter`=本文の最後 / `t`=見出しの下 / `h`=カーソル直下 / `i`=カーソルと同じ位置（行の中） / `c`=Context（新しいノートの `Context:` に今のノート） / `b`=ChildBranch（直接の子） / `p`=ParentBranch（直接の親） / `o`=リンク無し（孤立） / `r`=Related（両ノートに相互追加）
  `Enter` / `t` / `h` / `i` / `c` は、置き場所とは別に、元のノートを親・新しいノートを子とする Branch（元のノートの `ChildBranch:`、新しいノートの `ParentBranch:`）を自動で付ける。Context を足すのは `c` だけ。`b` は Branch だけ、`p` は向きが逆、`o` は孤立。`r` は Related だけを追加し、自動 Branch・Context や本文リンクは付けない。日記から作ったときの自動 Branch と重複の扱いは今までどおり
- `c` のあと（`zn` / `\l` / `za` 共通）… 相手（B）の `Context:` に今のノート（A）が入る。B に親（Branch）がまだ無ければ、A が B の親にもなる（最初の Context が親。スマホのメモと同じ）。続けて A のどこに B へのリンクを置くかを選ぶ: `Enter`=本文の最後 / `t`=見出しを選んでその節の最後 / `h`=カーソル直下 / `i`=行の中（カーソルの文字のすぐ後ろ） / `o`=どこにも置かない / `w`=置かずに B を `yn` と同じ方法でヤンク（A を開いたまま。自分で貼る）。`Esc` で取り消すと何も変わらない（質問はすべて変更の前）
- `a` のあと（`\l` / `za`。`c` の逆向き）… 今のノート（A）の `Context:` に選んだノート（B）が入る。A に親（Branch）がまだ無ければ、B が A の親にもなる。続けて B のどこに A へのリンクを置くかを選ぶ: `Enter`=本文の最後 / `t`=見出しを選んでその節の最後 / `o`=置かない / `w`=B には書かず、A へのリンクをヤンクして B を開く（`p` で自分で貼る。複数なら残りは `:GnosisWNext`）。`Esc` で取り消すと何も変わらない
- `b`（ChildBranch=直接の子）/ `p`（ParentBranch=直接の親）（`zn` / `za` / `\l` の位置キー）… `b` は今のノートが親・選んだ（作った）ノートが子、`p` は選んだ（作った）ノートが親・今のノートが子。どちらも内部では同じ処理で、**親のノートの `ChildBranch:` と、子のノートの `ParentBranch:`** の両方にリンクを書く。`p` で親にできるのは 1 つだけ。1 つのノートが持てる親（ParentBranch）は最大 1 つ（子は何本でも）。既に親があるノート・自分自身・循環になる組は拒否して、どちらのノートも変更しない（既存の親は付け替えない。現在の親のタイトルを表示）。Context / Related とは別の関係。`:GnosisBranchCheck` で整合性を検査
- グループの上の `zn` … `Enter`=表示名を入力して、このグループに登録して作る（グループの本文に表示名のリンク、新しいノートの `Group:` にグループ。新しいノートを開き、索引を `\S` と同じ規則で並べ替える） / `o`=孤立（どこにもつながない。あとで `\a` で整理）。ほかのキーは何もしない。BranchGroupから作る場合は、新ノートの `ParentBranch:` が起点のノートになる。`g`=グループへの登録だけ（起点を親にしない）。Context は付けない。通常のグループと `index.md` では Enter でも親は付けない
- BranchGroupに `za` で追加したノートも、親がなければ起点のノートを `ParentBranch:` にする（既存の親は保持）。`:GnosisGroupParent off` でこの自動設定を止め、`on` で戻す（セッション全体、`zn` にも適用。引数なしで切り替え）。1回だけ親なしで作るなら `zn` → `g`。
- `zk` … 通常のノートで `n` だけ: 今のノート（A）から分岐するグループ（G）を作る。A の `BranchGroup:` と `ChildBranch:` に G、G の `ParentBranch:` に A。Context は付けない。`BranchGroup:` にあるグループは A の `Group:` には重ねて出さない（G の本文の A へのリンクは残る）。グループの上では `zk` を使えない（ビジュアルも）
- 関係の見出しは `Group:` / `Context:` と同じ「名前:」の形（`ParentBranch:` / `ChildBranch:` / `Related:` / `BackLink:`。中身が空のものは書かない）。旧形式の `### 名前` の見出しも読めて、次の同期（`:UpdateAll`）で「名前:」の形に書き直される（リンクは 1 本も失わない。旧 `### Context` だけは `:GnosisContextMigrate! all` で移す）
- `BranchGroup:` の中は上から順に並べるだけ（リンクや関係は増えない）。段（インデント）は付けない（昔の段つきの行は sync で段なしに戻る）。紙の PKM（`\F`）のトピックは、その番号のスキャンノートの `BranchGroup:` に入る（親トピックがあれば、親とその子の後ろ）
- 同じノートを同じグループに別名でも追加できる。登録済みの場合は表示名の入力欄にその旨が出る。`Group:` のリンクは `[B:aaa]`、複数なら `[B:aaa,bbb]` のように、そのグループ内での表示名も示す。
- ノートの `Group:` からグループへのリンクを消すと、次の同期でそのグループの本文からもそのノートへのリンクが外れ、所属から抜ける（戻らない。グループの本文から消した場合は従来どおり `Group:` からも外れる）
- `zk`（ビジュアル）… 通常のノートで、選択範囲を中身にしたグループを作り、選択をそのグループへのリンクに置換（グループの上では使えない）
- `zh` … カーソル直下にリンク（本文扱い → 相手には BackLink）
- グループ（BranchGroup 方式）… 索引（Index）の入口は差し替えない。トピックの Index が欲しいときは、起点のノートで `zk` → `n`。グループへの登録は、グループの上の `zn` → `Enter` か、`\l` → `g`

## リンク

- `\L`（ノーマル）… カーソル下のファイル名を Markdown リンク化
- `\L`（ビジュアル）… 選択範囲を表示名にした新ノートへのリンクで選択を置換（新ノート title はタイムスタンプのまま）。最初につなぎ方を聞く: `b`=Branch（新しいノートを今のノートの子にする）/ `c`=Context（新しいノートの `Context:` に今のノート。親が無いので今のノートが親にもなる）/ `Enter`=つなげない（元ノートは BackLink に出るだけ）/ `Esc`=やめる
- `\p`（ノーマル）… カーソル下 or クリップボードのリンクを 1 本追加（`h`/`Enter` で位置を選ぶ）
- `\p`（ビジュアル）… クリップボードのファイル名/URL を選択範囲のリンクに（無ければ何もしない）
- `za` … クリップボード／ヤンクしたリンクを今のノートに追加（複数行・複数リンクも全部）。位置キーは `\l` と同じ（`Enter` / `i` / `t` / `h` / `c` / `b` / `p` / `r`、相手がグループなら `g`）。`Enter` は本文の最後に置くだけで、相手がグループでもグループへの登録にはしない
- `zA` … `za` と同じだが、追加前に**表示名**を入力する（空 Enter / Esc で中止）
- `Related:` … 両ノートで対になる関係（片側で消すと次回同期で両方から消える。BackLink には出ない）。通常ノートの `zn` / `\l` / `za` の最初の選択で `r`。既存の関係と本文を保持して両側に追加し、重複は作らず、片側だけなら反対側を補う。`c` の後の配置選択とは別
- `\P` … カーソル下のリンク先（B）の `Context:` に、今のノート（A）を確認なしで入れる。ビジュアルでは選んだ範囲のリンク先すべて。自分自身・無いノート・未保存の B は変えない
- 廃止したキー: `ca` / `cu` / `\ca` / `tt` / `ta` / `\at` / `\bc` / `zp` / `zap`（関数と `:CA` などのコマンドは残す。代わりは `c` の流れと `\P`）
- `\l`（ノーマル）… 全ノートを全文検索（タイトル優先）→ 選んだら置き場所を選ぶ: `Enter`=本文の最後 / `i`=行の中（`\l` を押したときのカーソルの文字のすぐ後ろに、そのまま入れる。関係は付けない） / `t`=見出しの下 / `h`=カーソル直下 / `c`=Context（リンク先の `Context:` に今のノート） / `a`=Context（今のノートの `Context:` にリンク先） / `b`=ChildBranch / `p`=ParentBranch / `r`=Related（相互） / `g`=選んだグループに今のノートを入れる（選んだノートがグループのときだけ） / `m`=マージ（1 つ選んだとき）。ほかのキーは何もしない（`:GnosisLinkPick`）
- `\l` → `m` … 選んだノートと開いているノートをマージする。続けて向きを選ぶ: `o`=開いているノートへ、選んだノートをまとめる / `s`=選んだノートへ、開いているノートをまとめる。まとめた側の本文が相手の本文の最後に入り、Context・BranchGroup・Related と、ほかのノートからのリンク（グループのメンバーも）は相手に移る（相手に親が無ければ親も）。まとめた側のノートは消える。スマホのメモの取り込み記録も相手を指すように直すので、二度取り込まない。`:GnosisMergeUndo` で直前のマージを元に戻せる（マージのあとに変えたノートがあれば、その変更も消えてよいか聞く）
- `\l` → `g` … 選んだノート（**グループ**＝`attribute: group`）に、**今のノートを入れる**。`\l` で検索してグループを選び、`g` を押すと、そのグループの本文に今のノートへのリンクが入り、今のノートの `Group:` にそのグループが出る。表示名を空欄から聞く（空 `Enter` = 今のノートのタイトル、入力して `Enter` = その文字、`Esc` = 取り消し）。続けてその表示名のよみを聞き（推測が入っている。直して `Enter`）、グループをよみの順に並べ替える。`zk` で分岐したグループ（今のノートの `BranchGroup:` にあるもの）にも同じ手順で入れる（`Group:` には重ねて出さない）。選んだノートがグループでなければ何もしない。今のノートの本文にはリンクを置かない。`za`（クリップボードのリンク）でも同じ。今のノートがグループでも使える（グループをほかのグループに入れる）
- `\l`（ビジュアル）… 同じ検索で選んだノートへのリンクで、選択範囲を置き換える（表示名は選択した文字。置き場所は聞かない）
- 自動生成の BackLink と、ここで入れたリンクは別もの。入れたリンク（表示名つきも）は保存・同期しても残る

## タイトル・表示名

- `zt` / `zT` … タイトル変更（空から / 現在を残して編集）
- `zl` / `zL` … リンク表示名の変更（空から / 現在を残して編集）
- `zo` … カーソル下の .md リンク先の見出し（アウトライン）を選び、リンク先に `#スラッグ` を付ける（先頭の「（見出しなし）」で解除。タイトルと Context/Group/Related/BackLink は一覧に出ない）
- `zy` / `zY` … **今開いているノート**の**よみ**を変更（`zy`=空欄から / `zY`=現在のよみを残して。`zY` で全部消して Enter は削除。Esc で中止）。`yomi:` に表示名が複数あるときは番号で表示名を選ぶ
- `zd` … 子リンクの表示名をリンク先タイトルに更新
- `mp` … YAML `filetype` を変更 ・ `yn` … 今のファイル名をヤンク ・ `\y` … 題と本文だけをコピー（`# 題` と本文。YAML と関係のブロック（`ParentBranch:` など・`ChildBranch:` / `BackLink:` など）は除き、ノートへのリンクは表示名だけにする。URL のリンクはそのまま）

## 移動・閲覧

- `<Tab>` / `<S-Tab>` … 次の / 前のリンクへ ・ `<CR>` … カーソル下のリンクを開く
- `<BS>` … 戻る ・ `<S-BS>` / `\.` … 進む ・ `_` … 直前のノートと往復
- `1`〜`9` / `0` … ドキュメントの上から順（冒頭の Context も含む）の通し番号のリンクを開く
- `\k` / `\m` / `\j` / `\J` … 一番上の「名前:」行（Group: や Context: など）へ / 本文の終わりから一番近い「名前:」行（ChildBranch: や BackLink: など）へ / BackLink の先頭へ / BackLink の末尾へ
- `\bu` … Context 付近の最後のリンクへ ・ `<S-Space>` … リンク一覧から選んで移動
- `\h` / `\0` … ハブ画面（編集可能なリンク一覧） ・ `\H` … 今のノートをハブに追加 ・ グループ（Index を含む）の上で `za` / `\l` で足すと、1 本ずつ**表示名**（空 `Enter` = リンク先のタイトル。`Esc` で全部取り消し）と、その**よみ**（推測が入っている。直して `Enter`、全部消すと登録しない）を聞いて入れ、よみの順に並べ替える（複数なら「(1/3)」のように順に）。手で貼って保存したときは**名前とよみの確認画面**が開く（`[表示名](…) — よみ`。推測には「（推測）」。表示名もよみも書き換えられ、行を消すとグループから外れる。`Enter` で中身を見る。`q` で保存して並べ替え、`Q` は保存せずに並べ替え。離れたら `:GnosisReview` で戻る。全員を見直すのは `:GnosisYomiReview`）・ `- [ ]` の行で挿入モードの Enter … 次の行にも `- [ ] ` を作る（空の項目で Enter ならやめる） ・ `\n`（`:GnosisQuick`）… とりあえず書く（何も聞かずにまっさらなノート。日記に自動で載る。つなぐのは後で） ・ `\M`（`:GnosisCaptureImport`）… USB でつないだスマホから Gnosis メモ APK のメモを取り込む（書き直したメモは同じノートへ差分だけ反映。PC と同じ場所を変えていたら競合として残し、`:GnosisCaptureConflicts` で見て `:GnosisCaptureResolve ID keep|append` で解決。旧版の別版は `:GnosisCaptureDuplicates` で一覧、旧ノートに追跡用の印を足すのは `:GnosisCaptureBackfill`（`apply` で書く）） ・ `\a`（`\N` も同じ。`:GnosisOrphans`）… 未所属（Folgezettel ID の無い）ノートの一覧（雑に書いたノートを後でつなぐ。グループ・日記・紙の PKM のノートは出ない）
- `\1`〜`\9` … ハブの N 番目へ直行（ハブ内では普通のリンク番号）
- `\i` … `index.md` を開く ・ `\A` … ノートアプリ（Electron / ブラウザ）
- `\q` … 作業タブの一覧（ノートの**タイトル**で表示。同じタイトルは補助にファイル名も出す）。`↑` / `↓`（`j` / `k`）で選び、`Enter` で切り替え、`Esc`（`q`）で閉じる。`/` はタイトルで絞り込み、`a` 追加 ・ `x` 閉じる ・ `X` 他を閉じる ・ `C` 全部閉じる（`:GnosisTabs`）
- `\o` … カーソル下のリンクを新しい作業タブで開く（`<CR>` は今のタブの中で移動。`:GnosisOpenLinkTab`）
- アプリ（`\A`）の `Alt+V` … 見るだけモード ⇔ 普通の Vim。見るだけ（下に VIEW）はカーソルを出さず、編集するキーは送らない。`j`/`k`・矢印・PageUp/Down・`gg`/`G`・`Ctrl-d`/`Ctrl-u` でスクロール。`/` `?` `n` `N` `*` `#` で検索。`gs`・`gm`・Space・Tab・`<CR>`・`<BS>`・`_`・数字・`\h` `\H` `\0` `\i` `\d` `\.` `\L` `\gi` `\r` `\bu` `\k` `\j` `\J` `\sc` も使える
- アプリでリンクを `Alt` + クリック … 開かずにカーソルだけをリンクへ動かす（カーソルだけを動かしたいときに使う）
- アプリは表（`| a | b |`）と `<img src="…" width="50%">` も描く。カーソルが表の中・インサート中は文字のまま
- `Ctrl-T`（`<C-t>`）… カーソルの位置に時刻（`時:分 ` と半角スペース）を入れる（ノーマルでは挿入モードに入って入れる。Vim 標準の Ctrl-T の字下げ・タグ戻りの代わり）・`\T`（`:GnosisTimeMode`）… 時刻モードのオン／オフ（そのノートだけ。ほかのノートへ移る・閉じると切れる。オンのあいだは空の行に書き始めると行の頭に時刻が入り、Enter で空行を 1 つはさむ。`#` `-` `*` `>` などの書き始めには入れない。時刻だけの行で Enter なら時刻を消す。チェックボックス・表の行はいつもどおり。時系列記録のノートは開くとオン。ステータスラインに「時刻」）

- 時系列記録 … 日記と同じ形で、夢などを日ごとのノートに書く。`:GnosisRecordNew 夢` で新しく作って今日のノートを開く。`\R`（`:GnosisRecord`）で一覧から選ぶと、今日のノートを作る・開く。今日の記録のリンクは、その日の日記の上（`ParentBranch:` の下・空行のあと）に並ぶ（「今日のノート」には入れない）。年が替わると、それまでの月を年のノートにまとめる。既存のグループを移すときは `:GnosisRecordMigrate 夢日記 夢`（題を改め、月を `YYYY-MM-夢` に、その日のノートを日記の上へ）。表記揺れで分かれた記録は `:GnosisRecordMerge ゆめ 夢` でまとめる（同じ日のノートは段落を時刻の順にまぜ、無い日のノートは移す。引数なしなら一覧から選ぶ）

## vault の暗号化（gocryptfs）

- vault は `A/note`（平文ビュー）+ `A/.crypt`（暗号実体）の兄弟構成。起動時にパスワードを聞いてマウントし、終了時に自動ロックする
- `:GnosisMount` … 手動マウント ・ `:GnosisLock` … 手動ロック（アンマウント）。別のウィンドウ・アプリが使っている vault は、ロックしない（`:GnosisLock!` で強制）
- 複数のウィンドウ（Vim・`\A` のアプリ）で、別々の vault も同じ vault も同時に開ける。暗号化 vault は、**使っている最後のウィンドウ**が終わる（または別の vault へ切り替える）ときだけロックされる。登録簿は vault の外（Gnosis ホームの `sessions/`）にあり、異常終了したプロセスの登録は自動で消える。同じノートを複数のウィンドウで編集して他で書き換えられたときは、自動保存は上書きせず、未保存の内容を `.state/conflicts/` に退避して警告する
- `:GnosisBackup` `[出力先]` … プロジェクトフォルダ（`.crypt` 他。`note/` の中身は除く）を vault のパスワードで 7z 化
- `:GnosisSetPassword` … 未暗号化なら暗号化、暗号化済みならパスワード変更
- `:GnosisRemovePassword` … 暗号化を解除して平文に戻す
- `:GnosisExitCleanup` … 終了時の後始末（viminfo 書き出し等）
- `:GnosisChooseIndex` / `:GnosisChooseIndexDir` … vault のフォルダを入力して選び直す（`A/note` があれば必ずそれを root に）
- 注意: gocryptfs は**空でないマウントポイントを拒否**する。中身とファイル名は暗号化されるが、時刻・サイズ・構造は漏れる

## ラベル記法（関係の接尾辞）

- `語:` … 相手側は `(語):` でミラー
- `語:;` … 相手側も `語:;`（括弧なし）
- `語;` … 相手側には書かない
- `語::` … 両方の同じセクションに `語:`
- **Context は本文の冒頭（H1 タイトルの直後）の `Context:` ブロック**（Markdown の見出しではなく、ふつうのテキスト行。直下にリンクが並ぶ）。`c` で足したリンクは既存リンクの最後に入り、同じノートは重複しない。旧形式 `### Context` も読める（`c` で足したノートは、リンクを失わず新形式へ移る。旧形式のノートは開いただけ・同期しただけでは書き換えない。移行は `:GnosisContextMigrate`（今のノート）/ `:GnosisContextMigrate all`（試走）/ `:GnosisContextMigrate! all`（vault 全体）で明示的に）。コードブロックの中の `Context:` は Context ではない
- グループ（`attribute: group`）へのリンクは `Group:` に、普通のノートへのリンクは `Context:` に、sync が自動で振り分ける。中身が空の節（ParentBranch / Group / ChildBranch / Related / BackLink）は見出しごと無い
- 本文にリンクがある子は `ChildBranch:` に書かない（本文の一覧がそのまま子の一覧。本文からリンクを消すと、子の `ParentBranch:` をもとに同期が `ChildBranch:` に戻す）。`BranchGroup:` の子は書く。`ChildBranch:` の中は、このノートを `Context:` にしている子が上、ただの子が下で、間に空行が 1 つ入る（同期が並べ直す。それぞれの中の並びは元のまま）
- Folgezettel ID（front matter の `folgezettel:`）は同期が振る。Index の本文に載っているノートが最上位の番号（`51`）、その Branch の子が `51a`、孫が `51a1` …（親が 1 つのものだけ）。番号は Branch の形に合わせる: 親を付け替えるなどして番号が親の番号の子でなくなったら、同期が新しい親の下の番号に振り直す（子孫も。使った番号は使い回さない。紙の PKM の番号は変えない）。日付の題（`2026-10-19-MO-…` など）のきょうだいは、作った順ではなく日付の順に振る。親の無い日記・時系列記録のその日のノートは最上位の番号になる。グループ（`attribute: group`）には振らない（付いていれば同期が外す）。ID の無いノートが未所属で `\a`（`\N`）に出る。Context だけで親の無い古いノートは `:GnosisBranchFromContext` で、最初の Context を親（Branch）にできる。`:GnosisFolgezettelMove` でオンにすると、`Ctrl-↑` / `Ctrl-↓` / `Ctrl-←` / `Ctrl-→` で番号の親・最初の子・前後のきょうだいへ移る（もう一度で切る）
- ノートの並び: `BranchGroup:` → `Group:` → `ParentBranch:` → `Context:`（ここまでは本文の上、H1 の直後のブロック。続くリンク行だけがブロックで、空行で終わる）→ 本文 → `ChildBranch:` → `Related:` → `BackLink:`（本文の下の節）。中身が空のものは書かない。`ParentBranch:` / `ChildBranch:` は `b` / `p` で明示した関係で、sync は追加も削除もしない（表示名の追従と、消えたファイルの掃除だけ。Context には変換しない）。カーソルがこれらのブロックの上にあるときの `h`（カーソル直下）は、リンクを本文に置く（ブロックには入れない）

## よみ順ソート

- `\S`（ノーマル）… **リンクだけの行**を表示名のよみ順（五十音 → ローマ字は末尾）に並べ替え（未登録のよみは `yomi:` に自動追加）。グループ（Index を含む）は本文のリンクが 30 本以上になると、「あ行＝あ」「か行＝か」の行見出しが入る。その行が30本を超えた場合だけ「あ・い・う・え・お」のように分ける（英字はまとめて「英字」。数字は「0-9」、ほかは「その他」）（並べ替えのたびに付け直す。30 本未満になれば外れる。濁音は清音の行に入る）
- `\S`（ノーマル・グループ）… グループでは、本文の最後の「空行で区切られたブロック」だけを並べ替える（それより上の文章・リンクは動かさない）
- `\S`（ビジュアル）… 選択した行のリンクだけの行を同じ規則で並べ替え（選択の外は変えない）
- `:SortYomi` / `:GnosisSortYomi` … `\S`（ノーマル）と同じ
- 文章（リンクでない行）・コードブロックの中と、本文の上のブロック（`ParentBranch:` / `BranchGroup:` / `Group:` / `Context:`）と、`ChildBranch:` / `Related:` / `BackLink:` 以降のリンクは動かさない。リンクが 0〜1 本なら何も変えない
- よみはリンク先ノートの front matter `yomi:`（表示名 → よみ）を優先。未登録は pykakasi で `yomi:` に自動追加
- `zy` / `zY` で表示名ごとのよみを手で修正/削除できる

- 紙のノート `1` と `1a` … `1a` の `ParentBranch:` に `1`、`1` の `ChildBranch:` に `1a`（Context では代用しない）。トピック（`1-タイトル`）の `ParentBranch:` は `1`。トピックは `folgezettel-Index-1` の `## 1` の節にも並ぶ（親トピックが先・インデントなし。親子は front matter の `topic_parent:`。親が分からないものは推測しない）
- 紙の日記 … その日のデジタル日記の、タイトルの下（空行 1 行・本文より上）に `[紙の日記]` のリンクが入る（再生成しても重複しない。デジタル日記が無い日は作らず、日記ができたあとの `\ua` でリンクする）。スキャン由来のノートは front matter の `source: scan` で、「今日のノート」に載せない

## スマホのメモ（Gnosis メモ APK）

- アプリを開いただけでは入力欄を選ばない（押すと書ける）。入力欄の横のボタンで入力欄を大きくできる。1 件 = 1 ノート。日記トピックは取り込むと日記の本文に時刻つきで入る。
- トピックは **全部・未所属・日記・その他** の 4 つだけ並ぶ。「その他」を押すとトピックの一覧（探す・新しいトピックを足す）。「全部」で書くと未所属。
- トピックごとの取り込み方は、一覧の歯車・足すときのスイッチで決める（両方オフなら 1 件 = 1 ノート。日記には使わない）。
  - **1 つのノートにまとめる**: PC に取り込むと、そのトピックの名前のノート（front matter の `capture_topic:`）に追記する。**時刻を付ける** なら日付の見出し（`## 2026-10-19（月）`。日が替わったときだけ）の下に `時:分 本文`、付けないなら本文だけ。ほかのメモから使われた（リンク・文脈・続き）メモだけは、本文の最初の 20 文字ほどを見出しにした節 `## 見出し` / 本文 / `##` になる（見出しにした部分も本文に残る。下に見出しが続くなら閉じの `##` は書かない）。使った側のリンクはその見出しを指す `[題#見出し](ノート.md#スラッグ)` になり、文脈・続きは本文の下に `文脈: …` `↳ … の続き` の行で残る。
  - **時系列記録**（PC の `:GnosisRecordNew` と同じ）: 日記のように、その日のノート `2026-10-19-MO-夢` に `時:分 本文` で入り、PC で同じ日に書いた分と時刻の順にまざる。その日の日記の上にリンク。PC にある記録の名前は `\M` のたびにスマホへ送られ、スマホではそこから選ぶ（表記揺れを防ぐ）。PC に無い名前なら `時系列記録` の中に新しく作る。
  - 選んでいるトピックの取り込み方は、入力欄の上に出る（押すと変えられる）。
- 表示の切り替え（上のバーの木のボタン / 時計のボタン）: **時系列**（いつもの、新しいものが下）と **Folgezettel**（続き＝Branch の親子を木にして上から `1`・`1a`・`1a1`・`1a1a`・`1a2`・`1b` … と番号つきで並べる）。Folgezettel では子のあるメモの左の ▾ / ▸ で、その下の子孫だけを折りたたむ・開く（`1a` をたたむと `1a1`・`1a1a`・`1a2` が隠れる）。上の「全部展開」「全部折りたたみ」でまとめて。親が別のトピックにあるメモは最上位に出る。
- 日記・時系列記録では、画面の上（タイトルの下）の「日付: 今日」を押すと日付を選んで、その日のメモとして書ける（PC に取り込むとその日の日記・記録に入る。先の日は選べない。トピックを変える・アプリを離れると今日に戻る）。日付を選んでいる間は隣に「今の時刻を入れる」が出る: オンなら PC では今の時刻（`時:分`）が付き、本文の最初に書いた日（「（2026-10-20 に記入）」）が入る。オフ（初め）なら時刻は付かない。設定の画面でも切り替えられる。
- トピックの名前は「その他」の一覧の鉛筆で変えられる（そのトピックのメモも新しい名前になる）。ゴミ箱のボタンでトピックを消せる（そのトピックのメモは消さずに未所属へ移す）。PC から届いた時系列記録の名前は変えも消しもできない（日記も）。
- 検索は空白（全角・半角）で区切ると、すべての語を含むメモ（順番は問わない）。全角・半角、大文字・小文字、カタカナ・ひらがなは区別しない。
- 上のバー: 虫めがね=メモの全文検索（全部のトピックから。結果を押すとそのメモへ）/ ＋=挿入（チェックボックス `- [ ] `・リンク・アウトライン引用・文脈・親）/ ⋮=複数選択・長いメモを全部展開する（折りたたむ）・取り込み済みのメモを消す・アラームと設定。長いメモはふだん途中までで、「続きを見る」で開く。
- アウトライン引用: メモを選び、メモに見出し（`#` の行）があれば見出しを選ぶ。`[題#見出し](memo:…#見出し)` が入り、取り込むとそのノートの見出しへのリンクになる。
- リンク・文脈・親は、メモを本文で探して選ぶ（リンク・文脈は複数可）。リンクは本文に `[表示名](memo:…)` として入り、取り込むと Gnosis のリンクになる。メモの中の「↳ の続き」「文脈:」「リンク:」を押すとそのメモへ飛ぶ。
- 右スワイプ=そのメモを文脈にして続ける（何件でも）、左スワイプ=そのメモの子（Branch）として続ける。長押し →「文脈・親を編集」で、あとから足す・外す。**親が無いときは最初の文脈が親（Branch）になる**（PC の `c` と同じ）。
- 複数選択: 統合（古い順に 1 件へ）・コピー・移動・消す。「ここから範囲選択」を押して終わりのメモを押す（または長押し）と、最後に選んだメモからそこまでをまとめて選ぶ。
- アラーム: 「鳴らす長さ（秒）」のあいだ音を繰り返す（0 で 1 回だけ。通知を押す・アプリを開くと止まる）。
- PC の `\a`（`\N`）も作成端末に関係なくトピック別に並ぶ（スマホで文脈・続きをつないだメモも、つないだ先に番号が無ければ出る）。行や複数行を選んで `t` でトピック変更（空欄で未所属）。`:GnosisTopic 仕事` でも変更できる。
- PC へは USB でつないで PC の Gnosis で `\M`。パスワードは要らない。取り込んだものはスマホで ✓ が付く。別 vault にも独立して取り込め、取り込みでスマホの原本が消えることはない。タイトルは冒頭20文字、本文はそのまま。
- 定期アラーム（スマホ右上の時計）: 初めは鳴らさない。「定期的に鳴らす」をオンにし、「何分おき」と時間帯を決める（「24時間鳴らす」をオンにすると時間帯は入力できない）。「何時まで」の時刻は含まない（9〜23 なら、最後に鳴るのは 22 時台）。鳴ったあと次にアプリを開くと日記で書き始め、閉じると全部の表示に戻る。通知の許可・音・次回時刻を設定で確認でき、テスト通知も鳴らせる。
- スマホに入れる手順（USB デバッグの許可を含む）は `docs/11-スマホのメモ.md` の「APK を作る・入れる」。PC からは `:GnosisApkInstall`。

## Vim の基本操作（詳細）

### モード
- ノーマル（起動時。`Esc` で戻る）… 移動・削除・コピー・貼り付けの土台
- 挿入 … `i` 前 / `a` 後 / `I` 行頭 / `A` 行末 / `o` 下に新行 / `O` 上に新行
- ビジュアル … `v` 文字 / `V` 行 / `<C-v>` 矩形。範囲を選んで `y` コピー `d` 削除 `c` 変更 `>` `<` インデント `~` 大小
- コマンドライン … `:`（Ex コマンド） / `/` `?`（検索）
- 迷ったら `Esc` を押してノーマルに戻る

### カーソル移動
- `h` `j` `k` `l` … 左 下 上 右（この環境は `j`/`k` = 表示行移動 `gj`/`gk`）
- `w` 次単語頭 / `b` 前単語頭 / `e` 単語末 / `ge` 前の単語末
- `0` 行頭 / `^` 最初の非空白 / `$` 行末
- `f<文字>` 次にその文字 / `t<文字>` その手前 / `F` `T` 逆方向 / `;` 繰り返し / `,` 逆の繰り返し
- `gg` 先頭 / `G` 末尾 / `{数}G` 指定行 / `H` `M` `L` 画面の上・中・下
- `<C-d>` 半画面下 / `<C-u>` 半画面上 / `<C-f>` 1画面下 / `<C-b>` 1画面上
- `zz` 中央 / `zb` 下（画面内の位置調整）
- `{` `}` 段落 / `(` `)` 文 / `%` 対応する括弧
- `<C-o>` 前のジャンプへ / `<C-i>` 次のジャンプへ

### 編集
- 削除: `x` 1文字 / `dd` 1行 / `dw` 単語 / `d$` 行末まで / `d` + モーション
- 変更: `cc` 1行 / `cw` 単語 / `ciw` 単語内 / `ci(` 括弧内
- コピー: `yy` 1行 / `yw` 単語 / `y$` 行末まで
- 貼り付け: `p` カーソルの後 / `P` 前（Vim 標準。PC の内容は `\v`）
- `r` 1文字置換 / `R` 上書き / `J` 行結合 / `~` 大文字小文字
- `u` 元に戻す / `<C-r>` やり直す / `.` 直前の変更を繰り返す
- 数え: `3j` `2dd` `5x` のようにコマンドの前に数字を置く
- インデント: `>>` `<<` / ビジュアルで `>` `<` / `=` 自動整形

### テキストオブジェクト（範囲を指定して編集）
- `iw` 単語 / `aw` 単語と空白 / `i"` `a"` 引用符の中 / `i(` `a(` 括弧の中 / `it` タグの中 / `ip` 段落
- 例: `ciw` で単語を書き換え / `di"` で引用符の中を削除 / `ya(` で括弧ごとコピー

### 検索
- `/語` 下へ検索 / `?語` 上へ / `n` 次 / `N` 前
- `*` カーソル下の単語を検索 / `#` 逆向き / `:noh` ハイライト解除

### コマンドライン
- `:w` 保存 / `:q` 終了 / `:wq` 保存して終了 / `:q!` 破棄して終了 / `:e ファイル` 開く
- `:bnext` `:bprev` バッファ移動 / `:help 語` ヘルプ / `:marks` マーク一覧
- この環境は保存時に自動同期（`:UpdateMD` / `:UpdateAll` で全体整合）

### レジスタ / クリップボード
- 無名 `"` / 番号 `0`〜`9` / 名前付き `a`〜`z` / システム `+` `*`
- `"ayy` で a にコピー / `"ap` で a を貼る
- PC のクリップボードは `\v` で貼る。`yy` `dd` `ciw` などでコピーした内容は PC 側にも流れる

### マーク / マクロ
- `ma` でマーク a / バッククォート + `a` でその位置へ / `:marks` で一覧
- `qa` 記録開始 / `q` 終了 / `@a` 再生 / `@@` 再実行

### この環境での Vim 標準との違い
- `j`/`k` は表示行移動（折り返した行も1行ずつ）。論理行は `+` / `-` や `{数}G` を使う
- `1`〜`9` `0` はリンクの番号ジャンプ（該当が無ければ数字はカウントとして素通り）
- `p` / `P` は Vim 標準。PC の内容を貼るのは `\v` / `\V`
- `_` は直前ノートと往復。`,`（f/t リピート）は標準のまま
- `zt` はタイトル変更（Vim 標準の「画面の上へ」ではない）。`zA` は表示名つきの追加
- プラグインの 2 文字コマンドは `z` / `g` / `\` 接頭辞（素のキーを待たせないため）
