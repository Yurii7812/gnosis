このノートは Gnosis の操作ガイド。**第 1 部**で基本の使い方（ノート・索引・`\l`・ダブルインデックス）を実際の操作の順に説明し、**第 2 部**でそのほかの機能を一通り説明する。**第 3 部**は説明を最小限にした**全機能の早見表**。
設定画面（`:GnosisSettings`）で言語を変えると、このガイドもその言語で作り直される。**Vim の基本操作は第 2 部の最後**。

## 第 1 部　はじめての人のための基本

ここは、Vim も Gnosis も初めての人が、**上から順にキーを押していけば最初のノートと索引ができる**ように書いてある。分からない言葉が出ても、そのまま読み進めてよい。

### 0. 読む前に — Vim が初めての人へ

- Gnosis は本物の **Vim**（キーボードだけで操作するエディタ）の中で動く。ノートは普通の Markdown ファイルで、1 つのノートが 1 つのファイル。ノートを入れるフォルダを **vault**（ボールト）と呼ぶ。
- **起動**: デスクトップのアイコン、またはターミナルで `gnosis`。最初の画面で `Enter` を押すと始まる。初めてなら `v` を押して、`n` で新しい vault（ノートを入れるフォルダ）を作る。
- **キーの書き方**: `Enter` と `Esc` はそのキー。`Ctrl-←` は Ctrl を押しながら ←。`zn` は `z` を押して、**続けて** `n` を押す（同時ではなく、1 つずつ順に）。`\l` は `\`（バックスラッシュ。日本語キーボードでは ¥ のキー）を押して、続けて `l`（エル）。
- **2 つの状態（モード）**: 起動直後は「**操作モード**」で、文字キーは文字を打たずに**命令**になる。文字を打つには「**入力モード**」に入る（`i` を押す）。入力モードから戻るのは `Esc`。**迷ったら `Esc` を 2 回押す**と、必ず操作モードに戻る。この文書のキーは、特に書いていなければ操作モードで押す。
- **動く**: 矢印キー（または `h` `j` `k` `l` = 左 下 上 右）。**保存は自動**（打つのをやめて約 1.5 秒で保存される。`Esc` でもすぐ保存）。**終わる**のは `\X`（全部閉じる。未保存のものは先に保存される）。
- **困ったとき**: まず `Esc` を 2 回。キーが分からなくなったら、曼荼羅ビューか リストビューで `?`（案内が出る）、または第 3 部の早見表。

### 1. 考え方 — ダブルインデックス方式

- Gnosis のノートは、**2 種類の「索引」(Index) のどちらかから辿れる**ようにつなぐ。本の「目次」と「項目別の索引」のようなもの。
- **Global Index**（`index.md`）… vault 全体の入口。`\i` でいつでも開ける。**Topic Index**（トピックの索引）… 話題ごとの小さな入口。ノートから枝分かれして作る。「グループ」とも呼ぶ。
- 道筋は次のとおり。広い入口（Global）から、話題ごとの狭い入口（Topic）へ降りていくので、ノートが増えても迷いにくい。

```
Global Index（index.md）
  ├─ 最初のノート「料理」 ── Topic Index「料理の索引」 ── 「カレー」「パスタ」…
  └─ 最初のノート「読書」 ── Topic Index「読書の索引」 ── 「小説」「論文」…
```

- 索引を必ず通る必要はない。最近のノート、全文検索（`gs`）、本文のリンク、曼荼羅ビューで辿るのも使える。ダブルインデックスは「体系的に探すときの道」。
- ノートどうしの関係は 4 種類。**Branch**（親子。Folgezettel の番号になる）・**Group**（索引に入っている）・**Context**（きっかけ・文脈）・**Related**（対になる関連）。リンクを書いて保存すれば、相手側の `BackLink:`（被リンク）などは同期が自動で書く。

### 2. 実際にやってみる — 「料理」のノートを作る例

**① 画面を確かめる**。起動すると、画面の左半分に**曼荼羅ビュー**（ノートのつながりを見る画面）、右半分に `index.md`（Global Index）が出る。カーソルは左にあるので、`Space` を押して右のノートの窓へ移る。

**② 最初のノートを作る**。Index の上で `zn` を押す。下に選択肢が出るので `Enter`（登録する）を押し、表示名に「料理」と入力して `Enter`。Index に「料理」のリンクが入り、**新しい空のノートが開く**。これが最初のノート（Index にあるノートは、最上位の番号 `1` `2` `3` … になる）。

**③ 題と本文を書く**。`zr` を押し、題（例: 料理）を入力して `Enter`。次に `i` を押して入力モードに入り、本文を書く。書き終わったら `Esc`。保存は自動。

**④ 続きのノート（子）を作る**。今のノートで `zn` → `Enter`（本文の最後にリンクが入る）。新しいノートが開くので、③と同じように題と本文を書く。**今のノートが親、新しいノートが子**になり、番号も親の子（`1a`）になる。
親を変えたり、ノートを消したりして木の形が変わると、**保存した時点で番号が自動で振り直され、欠番は詰まる**。`:UpdateMD` を手で実行する必要はない。親にできるのは 1 つだけ（子は何本でも）。

**⑤ 話題の索引（Topic Index）を作る**。「料理」のノートで `zk` を押し、続けて `n`。「料理」から枝分かれするグループができる。これが料理の話題の索引。
**索引にノートを入れる**: できたグループは、「料理」のノートの `BranchGroup:` のリンクから開ける（`<CR>`）。その索引を開いた状態で `zn` → `Enter`（新しいノートを作って登録）。または、すでにあるノートを `\l` → `e` → `g` で入れる（⑥で説明）。**表示名**と**よみ**（五十音順に並べるための読み）を聞かれ、入れると索引が五十音順に並ぶ。索引は入れ子にできる（`index.md` → 話題の索引 → さらに細かい索引）。

**⑥ `\l` で、すでにあるノートへのリンクを入れる**。リンクを入れたい場所のノートで `\l` を押す（そのノートが「元のノート」）。**入れたいノートを選ぶ画面**になるので、次のように選ぶ:

- 曼荼羅ビューでは `h` `j` `k` `l`（または矢印）でマスを動き、`Enter` で中心にする。リストビューでは `j` `k`（上下）・`h`（親）・`l`（子）・`[` `]`（兄弟）で動く。`gs` で全文検索して選ぶこともできる。
- **`Ctrl-←` / `Ctrl-→`（または `gv`）で、曼荼羅ビュー ⇔ リストビューを切り替えても、選ぶ画面は続く**。`o` を押すと元のノートが右に出る（もう一度押すと選んでいるノートに戻る）。
- `e` を押すと「**これにする**」（リストビューではカーソルの行のノート、曼荼羅では中心のノート）。やめるときは `q`。
- 続けて**置き場所**を聞かれる: `Enter`=本文の最後 / `t`=見出しの下 / `h`=カーソルの下 / `i`=行の中 / `v`=相手のノートの**一部**（右の相手のノートで `v` → カーソルで範囲を選ぶ → `Enter`。その範囲を本文にした新しいノートを作り、それを入れるノートにする。相手のノートは変わらない。1 つ選んだとき） / `c`=相手の Context に今のノート / `a`=今のノートの Context に相手 / `b`=相手を子に / `p`=相手を親に / `m`=2 つのノートをマージ / `g`=相手が索引なら、今のノートをその索引に入れる。迷ったら `Enter`。
- 文章の一部を選んで（`v` を押して矢印で選ぶ）から `\l` を押すと、**選んだ文字がそのノートへのリンクになる**。

**⑦ 見る・探す**。`Space` で左の画面（曼荼羅 / Folgezettel）と右のノートを行き来する。`Ctrl-←` / `Ctrl-→` で曼荼羅 ⇔ リストビュー。曼荼羅は中心のノートの周りに、つながったノートを 8 つ並べる。リストビューは番号順の一覧で、カーソルを動かすと右のノートも変わる（印の `▸` は `Enter` で開いたノートのまま）。`c` で印に戻る。
`gs` … vault 全体を全文検索。`\o` … 今のノートの見出し（アウトライン）を**右のパネル**に出す。`\h`（ハブ）・`\q`（タブのボード）も同じ右のパネルに出る（パネルは 1 つだけで、押したキーの中身に差し替わる）。同じキーをもう一度押すと、ノート ⇔ パネルを行き来する。パネルの中の `q` で閉じる。`Shift+→` / `Shift+←`（または `gl` / `gh`）で、左のビュー・ノート・右のパネルの間を 1 つずつ移る。`\W` … **ノートだけを表示する**（曼荼羅・パネルなど、全部の窓を閉じる。どの窓にカーソルがあっても同じ）。`\X` で終わる。

**⑧ 毎日**。`\d` … 今日の日記を開く（無ければ作る）。その日に作ったノートは、日記の「今日のノート」に自動で並ぶ。スマホのメモは USB でつないで `\M` で取り込む。保存のたびに自動で同期されるので、普段は何もしなくてよい。全体を整えたいときだけ `:UpdateMD`（または `\ua`）。

### 3. つまずいたとき

- **キーを押しても文字が出てしまう / 命令が効かない** … 入力モードになっている。`Esc` を押す。逆に、文字が打てないときは `i`。
- **画面が増えて分からなくなった** … `\W` を押すと、ノート 1 つだけの画面に戻る。曼荼羅はあとで `Space` や `\c` でまた開ける。
- **間違って作った・消した** … `u` で元に戻す。ノートを捨てたときは `\tr` でゴミ箱から戻せる。
- **番号がおかしい** … 保存すれば自動で直る。今までのズレをまとめて直すなら `:UpdateMD`。

## 第 2 部　そのほかの機能

### 曼荼羅・Folgezettel・リストビュー

- 起動したとき曼荼羅ビューが左半分に出る（設定 `mandalaOnStart`。`:GnosisSettings` で切り替え。既定オン）。閉じたときのビュー（曼荼羅・Folgezettel・リスト）と、幅・モードは、Vim を再起動しても前回のまま。
- **曼荼羅の動き**: `h` `j` `k` `l` / 矢印でマスを動く（右のノートも切り替わる）・`1`〜`8` でそのマスへ・`Enter` で中心にする・`Tab` / `S-Tab` で順に見る・`[` `]` で前後の曼荼羅・`b` / `⌫` で戻る・`\.` で戻るを戻す・`Space` でノートへ。
- **曼荼羅のモード**: `a` 全体 / `i` 索引だけ / `d` 親子だけ / `c` 近いグループ / `r` 予測関連 / `v` 外向き / `w` 近さ順 / `u` 見出し / `D` 配下だけ。`f` で 9×9 ⇔ 3×3、`p` で右のノートを隠す・出す、`L` で凡例。`s` 検索・`x` 絞り込み・`m` ハイライト（`n` `N`）。`q` で重なっているものを 1 つずつやめ、`Q` で全部閉じる。`Z` で設定の画面（プリセットは `'`）。
- **リストビューの動き**: `j` `k` で項目、`h` / `←` で親、`l` / `→` で下位（今開いているノートが下にあれば、その方向へ）、`[` `]` で前・次の兄弟、`Enter` でそのノートを開いて印を付け、**カーソルもそのノートの窓へ移る**（`\l` の選ぶモードの最中だけは、ビューに留まる）、`c` で印に戻る、`gg` `G` で先頭・末尾。`u` は上位表示（祖先と関連グループ。`M` で関連グループをもっと見る）。
- **幅は、曼荼羅・Folgezettel・リストビューで別々に覚える**（`<` `>` で変えた幅は、そのビューにだけ効く。切り替えるとそれぞれの幅に戻り、Vim を再起動しても同じ）。右のノートに移る（`Space`）と、**ノートの画面は一番上から表示され、カーソルだけがその同じ画面の一番下の行に置かれる**（曼荼羅ビューと リストビューで同じ。`\zz` で隠した部分や窓の大きさに合わせる。ノートの中でカーソルを動かしたあとは置き直さない）。
- **リストビューの番号**: 番号（`folgezettel:`）と題を並べる。同じ番号に BranchGroup があれば Group の行が上、Note の行が下。番号が長いときは先頭を `~` で省く（選ぶと下に全体が出る）。保存・同期で番号が変わると、表示も自動で読み直される。
- 両方のビュー共通: `f` `<` `>` `=` `p` `.` は全画面・幅・右の窓・読み直し、`?` で案内、`\c` `\C` でアプリ（GUI）と CUI の切り替え、`\x` で今の画面を閉じる、`\X` で全部閉じる。選ぶモード（`\l`）では `e` `I` `o` `q` が使える。

- **リストビュー**: `Ctrl+→` で曼荼羅 → Folgezettel → リスト → 曼荼羅、`Ctrl+←` は逆順（`gv` は次へ）。`1` 検索・`2` 類似・`3` リンク、`s` は gs と同じ検索をこの一覧に出す（ポップアップなし）。検索中の `S` は全部 → 索引とグループ → 索引以外。`+` で深さ（1〜10）、`w` で曼荼羅と同じ近さ順。リンクの `b` 子 / `p` 親 / `g` グループ / `c` 文脈 / `r` 関連 / `v` 引用 / `B` BackLink / `i` 索引 / `a` 全部は、移動せず関係で絞る。深さは最大300件。
- **一覧の検索と戻る操作**: リストとFolgezettelで `s` 検索・`x` 絞り込み・`m` ハイライト、`n` / `N` で一致する項目へ。入力は下の欄、Enterで確定、Escで元の条件に戻る。リストの `j` / `k` / 矢印で右にプレビュー（基準は固定）、Enterでそのノートに移り、リストの基準も移ったノートに変わる（リンク・類似はそのノートのもの。履歴は空になる）。`o` で、いま開いているノート（最後にEnterで開いたもの。まだ開いていなければ探索開始時のノート）・カーソル・スクロール位置へ戻り、Backspaceで一つ前の探索条件へ戻る。プレビューだけでは履歴は増えない。`q` は履歴を戻らず、リストを閉じる（戻るのはBackspace）。

### 右のパネル（アウトライン・ハブ・タブのボード）と窓の移動

- `\o`（`:GnosisOutline`）… 今のノートの見出し（`#` `##` `###` …）を**右のパネル**に出す。`\h` / `\0` … ハブ（編集できるリンク一覧）、`\q`（`:GnosisTabs`）… タブのボード。**パネルは右に 1 つだけ**で、押したキーの中身に差し替わる。
- **同じキーをもう一度押すと、ノートの窓 ⇔ パネル を行き来する。** パネルの中の `q` で閉じる。曼荼羅ビュー・リストビュー・パネルの中・ふつうのノートの、どこからでも同じ。ハブとボードは今までどおり編集できる（保存は自動）。
- `\q` のボードの中の `D` … **全部のタブを消す**（確認を 1 回聞く）。`\Q` … 今のノートをボードに足す。`\H` … 今のノートをハブに足す。
- アウトラインの中: `j` `k` で選び `Enter` で本文のその見出しへ（カーソルも本文へ移る）・`za` `zc` `zo` `zM` `zR` で折りたたみ・`<` `>` で幅・`s` で左右を入れ替え・`Space` で本文の窓へ。本文を編集すると自動で更新し、カーソルのある見出しを強調する。
- **パネルの幅**: パネルの中で `<` `>` は「境目を動かす向き」（曼荼羅の `<` `>` と同じ）。右のパネルでは、`<` で境目が左へ動いて広がり、`>` で右へ動いて狭まる。**窓の幅は勝手に動かない**: パネルを開けても閉じても、左のビュー（曼荼羅 / Folgezettel）の幅は変わらない（空いた分・足りない分はノートの窓が受け持つ）。
- **窓の移動**: `Shift+→` / `Shift+←`（予備に `gl` / `gh`）で、左のビュー（曼荼羅 / Folgezettel）→ ノート → 右のパネルの順に 1 つずつ移る。端では止まる。Vim の表記では `<S-Right>` / `<S-Left>`。Vim 標準の Shift+矢印（単語ごとの移動）は使えなくなるが、`b` `w` で同じことができる。
- `\W`（`:GnosisOnlyNote`）… **ノートだけを表示する**。曼荼羅・リストビュー・パネル・そのほかの分割窓を全部閉じて、ノートの窓 1 つにする（どの窓にカーソルがあっても同じ。曼荼羅は閉じたものとして覚える）。

### 検索

- `gs` … vault を全文検索（タイトル優先。左はタイトル、右はヒット箇所を強調）→ `⏎` でヒット行を開く（`:GnosisSearch`）
- 検索の書き方（`gs`・曼荼羅の `s` `x` `m` で同じ）… 空白 = AND、語の先頭の `-` = 除外（`ハーブ -メモ`）、前後に空白のある `|` = OR（`ハーブ | バジル`）、`"…"` = 空白を含む 1 つの語、演算子と同じ文字を探すときは `\` を付けるか `"…"` で囲む（語の途中の `-` や、空白のない `|` はそのまま文字）。大文字小文字・全角半角・カタカナ/ひらがなは区別しない
- 検索モード（`gs` / 通常・ビジュアルの `\l` 共通）… `Ctrl+→` / `Ctrl+↓` で次、`Ctrl+←` / `Ctrl+↑` で前へ循環: 全部（索引の表示名・グループ・タイトル・本文） → 索引とグループ → 索引以外（グループ・タイトル・本文）。現在モードは画面に表示。検索語は切替後も保持し、空の結果でも切替できる。普通の矢印は従来どおり
- 索引の表示名 … グループ（`index.md`・トピックIndexなど）の本文リンクのうち、リンク先の `Group:` に登録元グループがあるものだけ、その呼び名をリンク先への独立候補として表示。関係欄・コード内・通常ノートの本文リンクは含めない。同じリンク先でも表示名が違えば別候補、宛先と表示名が同じなら重複を除く。通常の `\l` はその表示名でリンクを追加し、ビジュアルの `\l` は元の選択文字列を使う。`gs` はリンク先を開く（表示名だけのヒットでは本文のヒット行へ移動しない）
- `rg` … ripgrep で全文（行）検索（`:Rg`）

### ノートとリンクの作り方（詳細）

- `zn` … ノート作成。位置キーを 1 つ選ぶ（ほかのキーは何もしない）:
  `Enter`=本文の最後 / `t`=見出しの下 / `h`=カーソル直下 / `i`=カーソルと同じ位置（行の中） / `c`=Context（新しいノートの `Context:` に今のノート） / `b`=ChildBranch（直接の子） / `p`=ParentBranch（直接の親） / `o`=リンク無し（孤立） / `r`=Related（両ノートに相互追加）
  `Enter` / `t` / `h` / `i` / `c` は、置き場所とは別に、元のノートを親・新しいノートを子とする Branch（元のノートの `ChildBranch:`、新しいノートの `ParentBranch:`）を自動で付ける。Context を足すのは `c` だけ。`b` は Branch だけ、`p` は向きが逆、`o` は孤立。`r` は Related だけを追加し、自動 Branch・Context や本文リンクは付けない。日記から作ったときの自動 Branch と重複の扱いは今までどおり
- `c` のあと（`zn` / `\l` / `za` 共通）… 相手（B）の `Context:` に今のノート（A）が入る。B に親（Branch）がまだ無ければ、A が B の親にもなる（最初の Context が親。スマホのメモと同じ）。続けて A のどこに B へのリンクを置くかを選ぶ: `Enter`=本文の最後 / `t`=見出しを選んでその節の最後 / `h`=カーソル直下 / `i`=行の中（カーソルの文字のすぐ後ろ） / `o`=どこにも置かない / `w`=置かずに B を `yn` と同じ方法でヤンク（A を開いたまま。自分で貼る）。`Esc` で取り消すと何も変わらない（質問はすべて変更の前）
- `a` のあと（`\l` / `za`。`c` の逆向き）… 今のノート（A）の `Context:` に選んだノート（B）が入る。A に親（Branch）がまだ無ければ、B が A の親にもなる。続けて B のどこに A へのリンクを置くかを選ぶ: `Enter`=本文の最後 / `t`=見出しを選んでその節の最後 / `o`=置かない / `w`=B には書かず、A へのリンクをヤンクして B を開く（`p` で自分で貼る。複数なら残りは `:GnosisWNext`）。`Esc` で取り消すと何も変わらない
- `b`（ChildBranch=直接の子）/ `p`（ParentBranch=直接の親）（`zn` / `za` / `\l` の位置キー）… `b` は今のノートが親・選んだ（作った）ノートが子、`p` は選んだ（作った）ノートが親・今のノートが子。どちらも内部では同じ処理で、**親のノートの `ChildBranch:` と、子のノートの `ParentBranch:`** の両方にリンクを書く。`p` で親にできるのは 1 つだけ。1 つのノートが持てる親（ParentBranch）は最大 1 つ（子は何本でも）。既に親があるノート・自分自身・循環になる組は拒否して、どちらのノートも変更しない（既存の親は付け替えない。現在の親のタイトルを表示）。Context / Related とは別の関係。`:GnosisBranchCheck` で整合性を検査
- グループの上の `zn` … `Enter`=表示名を入力して、このグループに登録して作る（グループの本文に表示名のリンク、新しいノートの `Group:` にグループ。新しいノートを開き、索引を `\S` と同じ規則で並べ替える） / `o`=孤立（どこにもつながない。あとで `\a` で整理）。ほかのキーは何もしない。BranchGroupから作る場合は、新ノートの `ParentBranch:` が起点のノートになる。`g`=グループへの登録だけ（起点を親にしない）。Context は付けない。通常のグループと `index.md` では Enter でも親は付けない
- BranchGroupに `za` で追加したノートも、親がなければ起点のノートを `ParentBranch:` にする（既存の親は保持）。`:GnosisGroupParent off` でこの自動設定を止め、`on` で戻す（セッション全体、`zn` にも適用。引数なしで切り替え）。1回だけ親なしで作るなら `zn` → `g`。
- `zk` … 通常のノートで `n` だけ: 今のノート（A）から分岐するグループ（G）を作る。A の `BranchGroup:` と `ChildBranch:` に G、G の `ParentBranch:` に A。Context は付けない。`BranchGroup:` にあるグループは A の `Group:` には重ねて出さない（G の本文の A へのリンクは残る）。グループの上では `zk` を使えない（ビジュアルも）
- 関係の見出しは `Group:` / `Context:` と同じ「名前:」の形（`ParentBranch:` / `ChildBranch:` / `Related:` / `BackLink:`。中身が空のものは書かない）。旧形式の `### 名前` の見出しも読めて、次の同期（`:UpdateAll`）で「名前:」の形に書き直される（リンクは 1 本も失わない。旧 `### Context` だけは `:GnosisContextMigrate! all` で移す）
- `BranchGroup:` の中は上から順に並べるだけ（リンクや関係は増えない）。段（インデント）は付けない（昔の段つきの行は sync で段なしに戻る）。紙の PKM（`\F`）のトピックは、その番号のスキャンノートの `BranchGroup:` に入る（親トピックがあれば、親とその子の後ろ）
- 同じノートを同じグループに別名でも追加できる。登録済みの場合は表示名の入力欄にその旨が出る。`Group:` のリンクは `[B:aaa]`、複数なら `[B:aaa,bbb]` のように、そのグループ内での表示名も示す。
- ノートの `Group:` からグループへのリンクを消すと、次の同期でそのグループの本文からもそのノートへのリンクが外れ、所属から抜ける（戻らない。グループの本文から消した場合は従来どおり `Group:` からも外れる）
- `zk`（ビジュアル）… 通常のノートで、選択範囲を中身にしたグループを作り、選択をそのグループへのリンクに置換（グループの上では使えない）
- `zh` … カーソル直下にリンク（本文扱い → 相手には BackLink）
- グループ（BranchGroup 方式）… 索引（Index）の入口は差し替えない。トピックの Index が欲しいときは、起点のノートで `zk` → `n`。グループへの登録は、グループの上の `zn` → `Enter` か、`\l` → `e` → `g`

- `\L`（ノーマル）… チェックボックス行では文章部分をビジュアル版と同じようにリンク化（チェック記号・インデントは残す）。それ以外ではカーソル下のファイル名を Markdown リンク化
- `\L`（ビジュアル）… 選択範囲を表示名にした新ノートへのリンクで選択を置換（新ノート title はタイムスタンプのまま）。最初につなぎ方を聞く: `b`=Branch（新しいノートを今のノートの子にする）/ `c`=Context（新しいノートの `Context:` に今のノート。親が無いので今のノートが親にもなる）/ `Enter`=つなげない（元ノートは BackLink に出るだけ）/ `Esc`=やめる
- `\p`（ノーマル）… カーソル下 or クリップボードのリンクを 1 本追加（`h`/`Enter` で位置を選ぶ）
- `\p`（ビジュアル）… クリップボードのファイル名/URL を選択範囲のリンクに（無ければ何もしない）
- `za` … クリップボード／ヤンクしたリンクを今のノートに追加（複数行・複数リンクも全部）。位置キーは `\l` と同じ（`Enter` / `i` / `t` / `h` / `c` / `b` / `p` / `r`、`g` は選んだグループに今のノートを入れる）。`Enter` は本文の最後に置くだけで、相手がグループでもグループへの登録にはしない
- `zA` … `za` と同じだが、追加前に**表示名**を入力する（空 Enter / Esc で中止）
- `Related:` … 両ノートで対になる関係（片側で消すと次回同期で両方から消える。BackLink には出ない）。通常ノートの `zn` / `\l` / `za` の最初の選択で `r`。既存の関係と本文を保持して両側に追加し、重複は作らず、片側だけなら反対側を補う。`c` の後の配置選択とは別
- `\P` … カーソル下のリンク先（B）の `Context:` に、今のノート（A）を確認なしで入れる。ビジュアルでは選んだ範囲のリンク先すべて。自分自身・無いノート・未保存の B は変えない
- 廃止したキー: `ca` / `cu` / `\ca` / `tt` / `ta` / `\at` / `\bc` / `zp` / `zap`（関数と `:CA` などのコマンドは残す。代わりは `c` の流れと `\P`）
- `\l`（ノーマル）… 曼荼羅で入れるノートを選ぶ（`Enter` で辿る・`gs` で検索して中心に・`e` で決定・`q` で取り消し。旧 fzf 版は `:GnosisLinkPick`）→ 選んだら置き場所を選ぶ: `Enter`=本文の最後 / `i`=行の中（`\l` を押したときのカーソルの文字のすぐ後ろに、そのまま入れる。関係は付けない） / `t`=見出しの下 / `h`=カーソル直下 / `v`=選んだノートの**一部**（右の選んだノートで `v` → カーソルで範囲を選ぶ → `Enter`。その範囲を本文にした新しいノートを作り、それを入れるノートにする。選んだノートは変わらない。1 つ選んだとき） / `c`=Context（リンク先の `Context:` に今のノート） / `a`=Context（今のノートの `Context:` にリンク先） / `b`=ChildBranch / `p`=ParentBranch / `r`=Related（相互） / `g`=選んだグループに今のノートを入れる（選んだノートがグループのときだけ。置き場所は聞かず、表示名とよみを聞いて終わり）/ `m`=マージ（1 つ選んだとき）/ `x`=向きを入れ替える（選んだノートの側にリンクを書く。1 つ選んだとき。`Enter` `i` `h` `t` は選んだノートの中で位置を選び、`p`⇔`b`・`c`⇔`a` は逆になる）。画面の見出しは `A に B のリンクを書く`（A=今のノート、B=選んだノート。題が長いときは `…`）。ほかのキーは何もしない
- `\l` → `m` … 選んだノートと開いているノートをマージする。続けて向きを選ぶ: `o`=開いているノートへ、選んだノートをまとめる / `s`=選んだノートへ、開いているノートをまとめる。まとめた側の本文が相手の本文の最後に入り、Context・BranchGroup・Related と、ほかのノートからのリンク（グループのメンバーも）は相手に移る（相手に親が無ければ親も）。まとめた側のノートは消える。スマホのメモの取り込み記録も相手を指すように直すので、二度取り込まない。`:GnosisMergeUndo` で直前のマージを元に戻せる（マージのあとに変えたノートがあれば、その変更も消えてよいか聞く）
- `\l` → `e` → `g` … 選んだグループに、今のノートを入れる。`\l` でグループを選び（曼荼羅なら `e` で決定、ノートにカーソルがあるときは `gs` の画面で選んで `Enter`）、`g` を押す。置き場所は聞かず、表示名とよみを聞く（空 `Enter` = ノートの題。ひらがな・カタカナ・英字だけの名前はよみを聞かない）。入力して `Enter` で終わり、グループはよみの順に並べ替わる（確認画面は出ない）。選んだノートがグループでないときは `g` は出ない。`za` でも同じ。`\g` は廃止した
- `\l` の置き場所の選択（曼荼羅で `e` のあと）… `q` / `Esc` はこの選択を閉じるだけで、`\l` は続く（曼荼羅で選び直せる。もう一度 `q` で `\l` をやめる）。`h`（カーソルの行の下）/ `i`（カーソルの文字の後ろ）/ `t`（カーソルがある節の最後）は、右に元のノートが出るので、そこでカーソルを動かして `Enter` で決める。`q` でやめると置き場所の選択に戻る。`c` `a` `m` などのサブの選択を `q` でやめたときも、置き場所の選択に戻る
- `\l`（ビジュアル）… 曼荼羅ビューで選んだノートへのリンクで、選択範囲を置き換える（`e` で決定すると選択肢が出る: `Enter` リンクにするだけ ／ 関係も結ぶ `p` `b` `c` `a` `r` `g` `m`。表示名は選択した文字。置き場所は聞かない。`q` でやめる）
- 自動生成の BackLink と、ここで入れたリンクは別もの。入れたリンク（表示名つきも）は保存・同期しても残る
- **名前とよみの一覧**: グループ（Index を含む）に `za` / `\l` で 2 本以上入れるとき、また、手で貼って保存したとき・`:GnosisYomiReview`（全員。`:GnosisReview` で開き直し）で、ポップアップに一覧が出る。`j` `k` で行を選び、`Enter` で表示名とよみを入力する（入力欄には今の名前と推測のよみが入っていて、そのまま `Enter` で決まる。よみは漢字を含む名前だけ聞く）。**入力した行は一覧から消える。** `s` … このまま（推測のよみ）・`A` … 残りを全部このまま・`d` … 入れない / グループから外す・`q` / `Esc` … やめる（入れる前の一覧では全部取り消し）。操作ガイドや時系列記録など、自動で入るものは聞かない。
- `zg` … **このノートが、グループの中でどう表示されているか**（グループの本文にある、このノートへのリンクの表示名）を変える。ノートの `Group:` / `BranchGroup:` のリンクの上で押すとそのグループ、それ以外の場所では、入っているグループが複数なら選ぶ。表示名が複数（`[B:aaa,bbb]`）なら、どれを変えるかも選ぶ。続けて表示名、漢字を含む名前ならよみも聞き、グループをよみの順に並べ直す（`Group:` の表示は同期で更新される）。グループの本文に載っていないノートでは何もしない。
- `zl` / `zL` … リンクの表示名を変える。グループ（Index を含む）の中のリンクなら、よみが要る名前のよみも聞いて（`\l` → `g` と同じ）、よみの順に並べ直す。

- 日記と時系列記録の木 … `時系列記録`（Index の本文に載る）> `日記` / `夢` > （年 `2026` / `2026-夢` >）月 `2026-10` / `2026-10-夢` > その日のノート。どれもグループではない普通のノートで（front matter に `timeline: true`）、親の本文に子のリンクが並び、子の `ParentBranch:` に親が入る（月の親は年、年が無ければ `日記`）。だから日記・月・年にも Folgezettel の番号が付く。年ができて月がその下に移ると、同期が月とその日のノート（とその子孫）の番号を振り直す。前の版のグループで作った木は、`\d` などで最初に開いたときに自動でこの形に直る（`python/diary_tree.py migrate`）
- 時系列記録 … 日記と同じ形で、夢などを日ごとのノートに書く。`:GnosisRecordNew 夢` で新しく作って今日のノートを開く。`\R`（`:GnosisRecord`）で一覧から選ぶと、今日のノートを作る・開く。今日の記録のリンクは、その日の日記の上（`ParentBranch:` の下・空行のあと）に並ぶ（「今日のノート」には入れない）。年が替わると、それまでの月を年のノートにまとめる。既存のグループを移すときは `:GnosisRecordMigrate 夢日記 夢`（題を改め、月を `YYYY-MM-夢` に、その日のノートを日記の上へ）。表記揺れで分かれた記録は `:GnosisRecordMerge ゆめ 夢` でまとめる（同じ日のノートは段落を時刻の順にまぜ、無い日のノートは移す。引数なしなら一覧から選ぶ） **DailyNotes:**（時系列記録の包含関係）… 各日の記録のノートの front matter に `parent_record: ビジネス`（上位の時系列記録の名前）を書くと、同じ日付の上位の記録のノートと日記の上（タイトルの下・本文の前）に、`DailyNotes:` の見出しで下位の記録へのリンクが自動で並ぶ。日記には最上位の記録だけ、各記録にはその日にある直接の下位だけ（その日に記録の無い中間は飛ばす。ただし下位へのリンクが 2 つ以上つく上位は、その日のノートを自動で作る）。リンクが無ければ `DailyNotes:` は出ない。手で書いたリンクと本文は変えない。`\E`（`:GnosisRecordParent`）… 今の記録の上位を、時系列記録の一覧から検索して選ぶ（「上位なし」で解除。循環は拒否）。上位は日ごとに持ち、新しい日のノートは、その日より前の直近の同じ系列のノートから引き継ぐ（未来の設定は使わない）。`\D`（`:GnosisRecordDate [YYYY-MM-DD]`）… 日付を指定して記録を作る・開く（`\R` は今日のまま）。（アプリ（`\c`）では `\D` でカレンダー付きの画面、`\E` で上位を検索して選ぶ画面が開く。どちらも同じ作成処理を使う） `:GnosisDailyNotes [日付]` … 整え直す（昔の日記の見出し無しのリンクを `DailyNotes:` に直す移行にも使う）
- 記録の種類（「時系列記録」の直下の「夢」など）を `zr` / `zR` で改題すると、年・月・日の件数を表示して一括改題するか確認する。`y` は種類と下の題の末尾をまとめて変更、`n` は種類だけ。衝突・未保存編集があれば中止。「日記」「時系列記録」自身は改題できない。

- `\R` … 時系列記録の選択画面。**`Ctrl-←` / `Ctrl-→`（`Tab` / `S-Tab`・`h` `l` も同じ）でモードを切り替える**: 開く（今日のノート）/ 日付を指定 / 新しく作る / 名前を変える / まとめる（マージ）。`j` `k` で記録を選び、`Enter` で決める、`Esc` でやめる。まとめるは「まとめる元（消える方）→ まとめる先（残る方）」の順に選ぶ。

### 関係・番号・同期の規則

- `語:` … 相手側は `(語):` でミラー
- `語:;` … 相手側も `語:;`（括弧なし）
- `語;` … 相手側には書かない
- `語::` … 両方の同じセクションに `語:`
- **Context は本文の冒頭（H1 タイトルの直後）の `Context:` ブロック**（Markdown の見出しではなく、ふつうのテキスト行。直下にリンクが並ぶ）。`c` で足したリンクは既存リンクの最後に入り、同じノートは重複しない。旧形式 `### Context` も読める（`c` で足したノートは、リンクを失わず新形式へ移る。旧形式のノートは開いただけ・同期しただけでは書き換えない。移行は `:GnosisContextMigrate`（今のノート）/ `:GnosisContextMigrate all`（試走）/ `:GnosisContextMigrate! all`（vault 全体）で明示的に）。コードブロックの中の `Context:` は Context ではない
- グループ（`attribute: group`）へのリンクは `Group:` に、普通のノートへのリンクは `Context:` に、sync が自動で振り分ける。中身が空の節（ParentBranch / Group / ChildBranch / Related / BackLink）は見出しごと無い
- 本文にリンクがある子は `ChildBranch:` に書かない（本文の一覧がそのまま子の一覧。本文からリンクを消すと、子の `ParentBranch:` をもとに同期が `ChildBranch:` に戻す）。`BranchGroup:` の子は書く。`ChildBranch:` の中は、このノートを `Context:` にしている子が上、ただの子が下で、間に空行が 1 つ入る（同期が並べ直す。それぞれの中の並びは元のまま）
- **Folgezettel の番号**（front matter の `folgezettel:`）は同期が振る。Index の本文に載っているノートが最上位の番号（`1` `2` `3` …）、その Branch の子が `1a`、孫が `1a1` …（親が 1 つのものだけ。親が複数あるノートは「今の番号の親 → `ParentBranch:` の最初」の親に従う）。
- **番号は木の形に毎回そろえる**: 親を付け替える・消す・新しく足すなどで形が変わると、保存した時点で全体を計算し直し、きょうだいは欠番なしに `1 2 3` / `a b c` と続く。順番は、日付の題なら日付順、それ以外は今の番号の順、新しいものは最後。変わらなければ何も書き換えない（何度回しても同じ）。`:UpdateMD` は、今までのズレや飛びをまとめて直したいときに使う。
- **所属のなくなったノートは番号を失う**: Index の本文にも日記にも載らず、`ParentBranch:`（親）も無いノートの番号は、同期が外す（親を外した・Index から外したとき）。その子（親が番号を失ったノート）の番号も同じ理由で外れる。あとで親を付け直すと、新しい番号が付く（元の番号には戻らない）。グループに入っているだけで親が無いノートも、そのグループが Index（`index.md`）でなければ番号は付かない。`\a`（未所属）には、**番号が無く、親も無い**ノートだけが出る（番号の無いノートを親にしている子は出ない。`BackLink:` `Context:` `Related:` があっても、親でなければ出る）。
- グループ（`attribute: group`）には番号を振らない（付いていれば同期が外す）。ただしブランチで作ったグループ（親の `BranchGroup:` にあるもの）は親と同じ番号を持つ。ID の無いノートが未所属で、`\a`（`\N`）に出る。Context だけで親の無い古いノートは `:GnosisBranchFromContext` で最初の Context を親にできる。`:GnosisFolgezettelMove` をオンにすると `Ctrl-↑` / `Ctrl-↓` / `Ctrl-←` / `Ctrl-→` で番号の親・最初の子・前後のきょうだいへ移る。
- ノートの並び: `BranchGroup:` → `Group:` → `ParentBranch:` → `Context:`（ここまでは本文の上、H1 の直後のブロック。続くリンク行だけがブロックで、空行で終わる）→ 本文 → `ChildBranch:` → `Related:` → `BackLink:`（本文の下の節）。中身が空のものは書かない。`ParentBranch:` / `ChildBranch:` は `b` / `p` で明示した関係で、sync は追加も削除もしない（表示名の追従と、消えたファイルの掃除だけ。Context には変換しない）。カーソルがこれらのブロックの上にあるときの `h`（カーソル直下）は、リンクを本文に置く（ブロックには入れない）
- 保存時に自動同期（`:UpdateMD` / `:UpdateAll` / `\ua` で全体を整合。`:UpdateAll` / `\ua` は index.md もよみ順に並べ替える）
- 相手側のラベルは自動でミラー。括弧を外して手書きしたら sticky
- 消えたファイルへのリンクは自動で掃除（行ごと。文章中のリンクは文字だけ残す）

### ハブ・ゴミ箱・よみ順

- `\1`〜`\9` … ハブへ直行 ・ `\H` … 現在ノートを登録 ・ `\0` / `\h` … 一覧
- ハブは Index（vault）ごとに保存。別の vault では別のハブ表になる
- `\tD` … 今のノートをゴミ箱（`.trash/`）へ移す（ソフト削除。`:GnosisTrash` も同じ）
- `\tr` … ゴミ箱を fzf で覗く（プレビュー付き）。`⏎`=開くだけ / `^r`=vault 直下へ復元して開く / `^e`=ゴミ箱を空にする（`:GnosisTrashList`）
- `\tE` … ゴミ箱を全部空にする（完全削除・確認あり。`:GnosisTrashEmpty` も同じ）
- `.trash/` はドット始まりなので検索・一覧・同期・リンクには出ない
- `\S`（ノーマル）… **リンクだけの行**を表示名のよみ順（五十音 → ローマ字は末尾）に並べ替え（未登録のよみは `yomi:` に自動追加）。グループ（Index を含む）は本文のリンクが 30 本以上になると、「あ行＝あ」「か行＝か」の行見出しが入る。その行が30本を超えた場合だけ「あ・い・う・え・お」のように分ける（英字はまとめて「英字」。数字は「0-9」、ほかは「その他」）（並べ替えのたびに付け直す。30 本未満になれば外れる。濁音は清音の行に入る）
- `\S`（ノーマル・グループ）… グループでは、本文の最後の「空行で区切られたブロック」だけを並べ替える（それより上の文章・リンクは動かさない）
- `\S`（ビジュアル）… 選択した行のリンクだけの行を同じ規則で並べ替え（選択の外は変えない）
- `:SortYomi` / `:GnosisSortYomi` … `\S`（ノーマル）と同じ
- 文章（リンクでない行）・コードブロックの中と、本文の上のブロック（`ParentBranch:` / `BranchGroup:` / `Group:` / `Context:`）と、`ChildBranch:` / `Related:` / `BackLink:` 以降のリンクは動かさない。リンクが 0〜1 本なら何も変えない
- よみはリンク先ノートの front matter `yomi:`（表示名 → よみ）を優先。未登録は pykakasi で `yomi:` に自動追加
- `zy` / `zY` で表示名ごとのよみを手で修正/削除できる

### vault の暗号化（gocryptfs）

- vault は `A/note`（平文ビュー）+ `A/.crypt`（暗号実体）の兄弟構成。起動時にパスワードを聞いてマウントし、終了時に自動ロックする
- `:GnosisMount` … 手動マウント ・ `:GnosisLock` … 手動ロック（アンマウント）。別のウィンドウ・アプリが使っている vault は、ロックしない（`:GnosisLock!` で強制）
- 複数のウィンドウ（Vim・`\c` のアプリ）で、別々の vault も同じ vault も同時に開ける。暗号化 vault は、**使っている最後のウィンドウ**が終わる（または別の vault へ切り替える）ときだけロックされる。登録簿は vault の外（Gnosis ホームの `sessions/`）にあり、異常終了したプロセスの登録は自動で消える。同じノートを複数のウィンドウで編集して他で書き換えられたときは、自動保存は上書きせず、未保存の内容を `.state/conflicts/` に退避して警告する
- `:GnosisBackup` `[出力先]` … プロジェクトフォルダ（`.crypt` 他。`note/` の中身は除く）を vault のパスワードで 7z 化
- `:GnosisSetPassword` … 未暗号化なら暗号化、暗号化済みならパスワード変更
- `:GnosisRemovePassword` … 暗号化を解除して平文に戻す
- `:GnosisExitCleanup` … 終了時の後始末（viminfo 書き出し等）
- `:GnosisChooseIndex` / `:GnosisChooseIndexDir` … vault のフォルダを入力して選び直す（`A/note` があれば必ずそれを root に）
- 注意: gocryptfs は**空でないマウントポイントを拒否**する。中身とファイル名は暗号化されるが、時刻・サイズ・構造は漏れる

### 紙の PKM（フォルゲゼッテル）

- `\F` … 紙のスキャンに番号を付ける。アプリ（GUI）では専用の大きな画面が開き、キーボードだけで使える。最初の画面で `p` を押すと、紙の番号の先頭の印（既定 `PA`）を変えられる。`\f` … 紙の PKM の Index を開く（無ければ作る。`:GnosisPaperIndex`）。更新は `\ua`。
- **紙のノートの番号は `PA-` を先頭に付けた形**（紙の `1a2` は `PA-1a2`、親は `PA-1a`）。デジタルのノートの番号（`1a2`）とは別の空間なので、ぶつからず、デジタル側に飛び番も出ない。先頭の印は設定 `paperIdPrefix`（`.gnosis/settings.json`）。`PB` などに変えると、同期で紙のノートの番号が全部付け直される。題は元の番号のまま。
- 紙の PKM が作るノート（Paper-Zettelkasten-Index・Index-write・Folgezettel-Index・`folgezettel-Index-N`・頂点のノート）は、**どれもふつうのノート**（ファイル名はタイムスタンプ。題で探す）。Paper-Zettelkasten-Index・Index-write・Folgezettel-Index は、頂点のノートと同じ番号になる。
- `Index-write` … `キーワード(よみ): 1,1a10b,3` の形式で手書き。複数IDのキーワードはグループノート、単一IDは直接リンクとして紙PKM Index に並ぶ（保存で自動再生成）
- `\S` … Index-write ではキーワード行もよみ順に並べる
- Folgezettel-Index は存在する全IDの一覧（自然順）。生成物なので `\S` しない
- 紙のノート `1` と `1a` … `1a` の `ParentBranch:` に `1`、`1` の `ChildBranch:` に `1a`（Context では代用しない）。トピック（`1-タイトル`）の `ParentBranch:` は `1`。トピックの Index は `folgezettel-Index-1` の先頭（ノートの `## 1` の節より前）に並ぶ（親トピックが先・インデントなし。親子は front matter の `topic_parent:`。親が分からないものは推測しない）
- 紙の日記 … その日のデジタル日記の、タイトルの下（空行 1 行・本文より上）に `[紙の日記]` のリンクが入る（再生成しても重複しない。デジタル日記が無い日は作らず、日記ができたあとの `\ua` でリンクする）。スキャン由来のノートは front matter の `source: scan` で、「今日のノート」に載せない

### スマホのメモ（Gnosis メモ APK）

- アプリを開いただけでは入力欄を選ばない（押すと書ける）。入力欄の横のボタンで入力欄を大きくできる。1 件 = 1 ノート。日記トピックは取り込むと日記の本文に時刻つきで入る。
- トピックは **全部・未所属・日記・その他** の 4 つだけ並ぶ。「その他」を押すとトピックの一覧（探す・新しいトピックを足す）。「全部」で書くと未所属。
- トピックごとの取り込み方は、一覧の歯車・足すときのスイッチで決める（両方オフなら 1 件 = 1 ノート。日記には使わない）。
  - **1 つのノートにまとめる**: PC に取り込むと、そのトピックの名前のノート（front matter の `capture_topic:`）に追記する。**時刻を付ける** なら日付の見出し（`## 2026-10-19（月）`。日が替わったときだけ）の下に `時:分 本文`、付けないなら本文だけ。ほかのメモから使われた（リンク・文脈・続き）メモだけは、本文の最初の 20 文字ほどを見出しにした節 `## 見出し` / 本文 / `##` になる（見出しにした部分も本文に残る。下に見出しが続くなら閉じの `##` は書かない）。使った側のリンクはその見出しを指す `[題#見出し](ノート.md#スラッグ)` になり、文脈・続きは本文の下に `文脈: …` `↳ … の続き` の行で残る。
  - **時系列記録**（PC の `:GnosisRecordNew` と同じ）: 日記のように、その日のノート `2026-10-19-MO-夢` に `時:分 本文` で入り、PC で同じ日に書いた分と時刻の順にまざる。その日の日記の上にリンク。PC にある記録の名前は `\M` のたびにスマホへ送られ、スマホではそこから選ぶ（表記揺れを防ぐ）。PC に無い名前なら `時系列記録` の中に新しく作る。
  - 選んでいるトピックの取り込み方は、入力欄の上に出る（押すと変えられる）。
- 表示の切り替え（上のバーの木のボタン / 時計のボタン）: **時系列**（いつもの、新しいものが下）と **Folgezettel**（続き＝Branch の親子を木にして上から `1`・`1a`・`1a1`・`1a1a`・`1a2`・`1b` … と番号つきで並べる）。Folgezettel では子のあるメモの左の ▾ / ▸ で、その下の子孫だけを折りたたむ・開く（`1a` をたたむと `1a1`・`1a1a`・`1a2` が隠れる）。上の「全部展開」「全部折りたたみ」でまとめて。親が別のトピックにあるメモは最上位に出る。
- 右スワイプ=そのメモを文脈にして続ける（何件でも）、左スワイプ=そのメモの子（Branch）として続ける。長押し →「文脈・親を編集」で、あとから足す・外す。**親が無いときは最初の文脈が親（Branch）になる**（PC の `c` と同じ）。
- PC の `\a`（`\N`）も作成端末に関係なくトピック別に並ぶ（スマホで文脈・続きをつないだメモも、つないだ先に番号が無ければ出る）。行や複数行を選んで `t` でトピック変更（空欄で未所属）。`:GnosisTopic 仕事` でも変更できる。
- PC へは USB でつないで PC の Gnosis で `\M`。パスワードは要らない。取り込んだものはスマホで ✓ が付く。別 vault にも独立して取り込め、取り込みでスマホの原本が消えることはない。タイトルは冒頭20文字、本文はそのまま。
- スマホに入れる手順（USB デバッグの許可を含む）は `docs/11-スマホのメモ.md` の「APK を作る・入れる」。PC からは `:GnosisApkInstall`。
